## 🌌 关于衡元宙

衡元宙（全称"万灵衡锚本源宙"）是一个以**锚点共生文明**为核心的多元宇宙设定体系。与传统修真/玄幻世界的"掠夺体系"（强者掠夺弱者、力量即支配权、零和博弈）根本不同，衡元宙建立在**共生体系**之上：

- **力量来自共生连接**，而非掠夺牺牲
- **万族平等共和**，而非强者支配弱者
- **资源循环共享**，而非零和分配
- **永续共生发展**，而非毁灭轮回

## 🖥️ 文明仿真（项目12）

大规模多轮文明迭代数值仿真，对比掠夺文明与锚点共生文明的演化差异：

- **引擎**：Python，纯数值仿真
- **场景**：32个（2文明×4人口×4位面）
- **迭代**：每场景500轮
- **输出**：
  - `civilization_evolution_full.csv`：全量逐轮数据（16000行×20字段）
  - `civilization_evolution_summary.csv`：场景级汇总（32行）
  - `civilization_evolution_presets.csv`：沙盘预设曲线（1600行）
  - `simulation_run.log`：运行日志

**关键发现**：
- 存活率：掠夺文明81.2%，锚点共生81.2%（相同）
- 冲突次数：掠夺文明33-332次/场景，锚点共生0次/场景
- 平均稳定性：掠夺文明0.01-0.65，锚点共生0.80-0.997
- **结论**：存活率相同，但生存质量天差地别

### 运行仿真

```bash
cd simulation
python3 src/civilization_simulator.py
```
