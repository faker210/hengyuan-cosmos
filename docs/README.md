## 项目简介

本仓库是"锚点共生文明"的完整设定总库，收录100份核心设定文档，覆盖宇宙总纲、修炼体系、锚点机制、文明分型、法律体系、种族生命、技术能量、历史纪元、跨位面规则及附录索引十大模块。

锚点共生文明以"反掠夺、倡共生"为核心理念，主张将命运与进化的选择权交还给众生，践行"多劳多得、自生自长、人人有路、万族共进"的基本纲领，通过开放三百套宇宙本源修炼体系、建立宇宙版联产承包机制、激活20%众生成为位面至高强者，探索一条集体共生进化的升维之路。
