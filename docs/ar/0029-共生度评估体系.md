## أولاً: معنى درجة التكافل وأغراضها

درجة التكافل المؤشر المركزي لقياس سلامة تشغيل الشبكة التكافلية للمراسي، وتعكس درجة التكافل بين جميع كائنات الشبكة. إنها ليست رقماً واحداً، بل منظومة مؤشرات شاملة تغطي أبعاداً متعددة: نمو الفرد، وتماسك الجماعة، وتوزيع الموارد، وتشغيل الشبكة.

أغراض إنشاء منظومة تقييم درجة التكافل:

1. **رصد الحالة**: معرفة حالة تشغيل الشبكة التكافلية لحظياً واكتشاف المشكلات في وقتها
2. **تقييم الأثر**: تقييم آثار تنفيذ السياسات التكافلية الكبرى، توفيراً لأساس تعديل السياسات
3. **توجيه التطور**: توفير الاتجاه لتطور الحضارة التكافلية عبر تحليل المؤشرات
4. **الإنذار المبكر**: إطلاق إنذارات مبكرة عند هبوط درجة التكافل أو ظهور شذوذ، منعاً لتدهور النظام التكافلي

يتبع تقييم درجة التكافل مبادئ الموضوعية والشمول والديناميكية والشفافية: البيانات موضوعية صادقة؛ والمؤشرات تغطي كل الأبعاد المهمة؛ والتقييم يُعدل ديناميكياً حسب الواقع؛ وعملية التقييم ونتائجه شفافة مفتوحة.

## ثانياً: نموذج مؤشرات درجة التكافل

تعتمد درجة التكافل نموذج مؤشرات متعدد المستويات، منقسماً إلى ثلاثة مستويات: مؤشرات المستوى الأول (4)، ومؤشرات المستوى الثاني (12)، ومؤشرات المستوى الثالث (بنود قياس محددة). هذا هيكل مؤشرات المستويين الأول والثاني:

| مؤشر المستوى الأول | مؤشر المستوى الثاني | محتوى القياس |
|----------|----------|----------|
| مؤشر تطور الفرد | مؤشر تقدم الزراعة | متوسط تقدم الزراعة وتوزيع المراتب لجميع الكائنات |
| | مؤشر عدالة النمو | فروق النمو بين كائنات المناطق والأعراق والطبقات المختلفة |
| | مؤشر رضا الفرد | تقييم الفرد الذاتي للشبكة والسياسات |
| مؤشر تماسك الجماعة | مؤشر المشاركة الشبكية | مشاركة جميع الكائنات في بناء الشبكة وصيانتها |
| | مؤشر الوفاء بالمسؤوليات | إتمام حقول المسؤولية العامة لدى جميع الكائنات |
| | مؤشر الهوية الثقافية | درجة الانتماء للثقافة والفلسفة التكافليتين |

| مؤشر تشغيل الشبكة | مؤشر استقرار الشبكة | استقرار تشغيل شبكة المراسي ومعدلات الأعطال |
| | مؤشر نقل الطاقة | كفاءة نقل الطاقة وفاقدها |
| | مؤشر الأمن | حالة أمن الشبكة تجاه التهديدات الخارجية |

### 2.1 مؤشر تطور الفرد

يقيس مستوى تطور كل كائن في الشبكة. يشمل ثلاثة مؤشرات ثانوية: تقدم الزراعة، وعدالة النمو، ورضا الفرد.

يعكس مؤشر تقدم الزراعة متوسط مستوى الزراعة لجميع الكائنات، محسوباً على أساس توزيع المراتب. يعكس مؤشر عدالة النمو فروق فرص النمو وسرعاته بين الكائنات؛ كلما قل الفرق زادت العدالة. يحصل مؤشر رضا الفرد عبر استطلاعات رضا منتظمة، معكساً تقييم الأفراد الذاتي للشبكة.

### 2.2 مؤشر تماسك الجماعة

يقيس درجة اتحاد الحضارة وتعاونها ككل. يشمل: المشاركة الشبكية (المشاركة في البناء والصيانة والحكم)، والوفاء بالمسؤوليات (إتمام الحقول)، والهوية الثقافية (الانتماء للثقافة والفلسفة، عبر استطلاعات وتحليل سلوكي).

### 2.3 مؤشر توزيع الموارد

يقيس عدالة وكفاءة توزيع الموارد. يشمل: عدالة الموارد (فرق حيازة الفرد الواحد بين المناطق والطبقات)، وكفاءة الموارد (معدل تحويل الموارد إلى نتائج زراعية)، واستدامة الموارد (سرعة تجدد البرك والاحتياطات مقابل الاستهلاك).

### 2.4 مؤشر تشغيل الشبكة

يقيس المستوى التقني لتشغيل الشبكة. يشمل: استقرار الشبكة (معدلات الأعطال، وتواتر المعايرة، وأزمنة التوقف)، ونقل الطاقة (الكفاءة والفاقد، المرتبطان بمنافع الشبكة الاقتصادية)، والأمن (تواتر الهجمات ومعدلات نجاح الدفاع).

## ثالثاً: جمع البيانات ومعالجتها

### 3.1 جمع البيانات

تأتي بيانات درجة التكافل أساساً من القنوات التالية:

1. **الجمع الآلي**: تجمع شبكة المراسي تلقائياً بيانات حالة الزراعة وتدفق الطاقة وتشغيل الشبكة لحظياً
2. **الاستطلاعات المنتظمة**: استطلاعات رضا وهويات ثقافية منتظمة لبيانات التقييم الذاتي
3. **الاستطلاعات الخاصة**: لمؤشرات محددة (كعدالة النمو)، استطلاعات خاصة لبيانات معمقة
4. **المعلومات الخارجية**: جمع معلومات التهديدات الخارجية وتغيرات البيئة الكونية

يتبع الجمع بصرامة مبدأي «الحد الأدنى الضروري» و«حماية الخصوصية»: لا يجمع إلا ما يلزم لحساب المؤشرات، وتُنكر هوية كل البيانات الشخصية.

### 3.2 معالجة البيانات

البيانات الأولية المجموعة تحتاج معالجة قبل حساب المؤشر، تشمل:

1. **تنقية البيانات**: إزالة الضجيج والقيم الشاذة والسجلات المكررة
2. **التوحيد**: توحيد بيانات الأبعاد والوحدات المختلفة إلى نطاق قابل للمقارنة
3. **تحديد الأوزان**: تحديد وزن لكل مؤشر حسب أهميته
4. **حساب المؤشر**: تجميع مرجح لمؤشرات جميع المستويات للحصول على درجة التكافل الكلية

تحديد الأوزان ليس ثابتاً، بل يُعدل حسب مرحلة تطور الحضارة. مثلاً، في المرحلة المبكرة قد تكون لمؤشرات بناء الشبكة أوزان أعلى؛ وفي مرحلة النضج قد تكون لمؤشرات تطور الفرد أوزان أعلى.

## رابعاً: تطبيق نتائج التقييم والإنذار المبكر

### 4.1 تطبيق نتائج التقييم

تستخدم نتائج تقييم درجة التكافل أساساً في الجوانب التالية:

1. **صياغة السياسات**: صياغة السياسات التكافلية وتعديلها بناء على النتائج
2. **توزيع الموارد**: تعديل خطة التوزيع حسب القصور الذي تعكسه المؤشرات
3. **تحسين المناطق**: تقديم اتجاهات تحسين محددة للمناطق ذات المؤشرات الأدنى
4. **تحسين التغذية الراجعة**: إدخال النتائج في آلية دورة التغذية الراجعة، دافعة التحسين المستمر للشبكة

### 4.2 آلية الإنذار المبكر

حين تبلغ درجة التكافل أو مؤشراتها الفرعية عتبات الإنذار، تُفعل آلية الإنذار:

| مستوى الإنذار | شرط الإطلاق | إجراءات الاستجابة |
|----------|----------|----------|
| إنذار أزرق | مؤشر ثانوي واحد دون خط الإنذار 3 دورات متتالية | تتبع مركّز للمؤشر المعني، وتحليل السبب |
| إنذار أصفر | مؤشر أول واحد دون الخط 3 دورات متتالية | عقد اجتماع تقييم خاص، وصياغة خطط تحسين |
| إنذار برتقالي | هبوط الدرجة الكلية دون الخط، أو هبوط مؤشرين أوليين معاً | تعبئة إجراءات تحسين على مستوى الحضارة كلها |
| إنذار أحمر | هبوط متواصل 6 دورات أو هبوط حاد | تفعيل خطة الطوارئ، وتحقيق وتصويب شاملان |

### 4.3 الشفافية والإشراف

عملية ونتائج تقييم درجة التكافل مفتوحة لجميع الكائنات، خاضعة لإشراف الحضارة كلها. يستطيع كل كائن الاستعلام عن بيانات التقييم وطرق حساب المؤشرات المعنية. وإذا شك كائن في النتائج، يستطيع طلب إعادة تقييم لدى هيئة التقييم.

## الخاتمة

منظومة تقييم درجة التكافل هي «منظومة الفحص الصحي» للشبكة التكافلية للمراسي، وتزود الحضارة التكافلية بقدرات رصد وتقييم موضوعية وشاملة وديناميكية. بالتشغيل المستمر لمنظومة المؤشرات، تستطيع الحضارة اكتشاف المشكلات في وقتها، وتحسين السياسات بسرعة، وتعديل اتجاه التطور، وتقود الشبكة في النهاية نحو تطور أكثر صحة وازدهاراً. درجة التكافل ليست مؤشراً تقنياً فحسب، بل تجسيد ملموس لقيم الحضارة التكافلية — درجة التكافل هي مقياس تقدم الحضارة.
