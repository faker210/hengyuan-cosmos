# فهرس المواد القانونية

| العنصر | المحتوى |

| الكلمات المفتاحية | الفهرس القانوني، الدستور التكافلي، قانون العمل، قانون حماية المستهلك، القوانين المرافقة |

## أولاً: ملاحظات حول الفهرس

يجمع هذا الفهرس الوثائق القانونية الرئيسية السارية في حضارة التكافل المرساة وموادها الجوهرية، مصنفة حسب التسلسل القانوني والتخصص. يغطي نطاق الفهرس الدستور التكافلي، وقانون العمل التكافلي، وقانون حماية المستهلك، إضافة إلى خمسة قوانين مرافقة هي التعليم والرعاية الطبية والإسكان والبيئة ومكافحة الاحتكار. تذكر كل مدخلة اسم القانون ورقم المادة وملخصاً للمحتوى الجوهري للمادة. هذا الفهرس أداة استرشاد؛ أما النص الكامل للمواد القانونية والتفسيرات القضائية فتراجع في النصوص الرسمية للقوانين المعنية.

## ثانياً: الدستور التكافلي

الدستور التكافلي هو القانون الأساسي لحضارة التكافل المرساة، يتمتع بأعلى قوة قانونية، ووُضع عند التأسيس الرسمي للحضارة التكافلية.

| رقم المادة | المحتوى الجوهري |
|----------|----------|
| المادة الأولى | يثبت كون هنغ يوان (الكون الأصلاني وانلينغ هنغماو) مجال حكم حضارة التكافل المرساة؛ والغرض الأساسي للحضارة التكافلية هو تحقيق تكافل عشرة آلاف عرق وارتقاء الكون |
| المادة الثانية | يثبت معاداة الافتراس موقفاً أساسياً للحضارة، ويحظر الزراعة الافتراسية ونهب الموارد بأي شكل |
| المادة الثالثة | يثبت «إعادة حق اختيار المصير والتطور إلى جميع الكائنات الحية» مفهوماً جوهرياً للحضارة |
| المادة الرابعة | يثبت عملاً أكثر ربحاً أكثر، ونمواً ذاتياً، وطريقاً لكل فرد، وتقدماً مشتركاً لعشرة آلاف عرق سياسات أساسية للحضارة |
| المادة الخامسة | يثبت نظام الفتح المجاني لأنظمة الزراعة الأصلانية الثلاثمائة؛ ولا يجوز لأي منظمة أو فرد احتكار حقوق نقل أنظمة الزراعة |
| المادة السادسة | يثبت آلية العقود المرتبطة بالإنتاج نظاماً أساسياً لتوزيع الموارد |
| المادة السابعة | يثبت استراتيجية التنشيط بنسبة 20٪ هدفاً وطنياً مرحلياً |
| المادة الثامنة | يثبت مبدأ الواقع أساس: العالم الواقعي هو العالم الحقيقي الوحيد، ولا قوة قانونية للإعدادات الخيالية |
| المادة التاسعة | يثبت مسار الارتقاء بأربع مراحل استراتيجية تنمية طويلة الأمد للحضارة |
| المادة العاشرة | يثبت مبدأ مساواة عشرة آلاف عرق؛ جميع أشكال الحياة متساوية أمام القانون |
| المادة الحادية عشرة | يثبت مبدأ التطور التكافلي؛ لا يجوز أن يتم التطور الفردي على حساب حقوق تطور أفراد أو جماعات أخرى |
| المادة الثانية عشرة | يثبت مبدأ عملاً أكثر ربحاً أكثر؛ يقوم توزيع الموارد على المساهمة كأساس جوهري |
| المادة الثالثة عشرة | يثبت مبدأ النمو الذاتي؛ يحترم حق كل كائن حي في الاختيار الذاتي للتطور |
| المادة الرابعة عشرة | يثبت مبدأ طريق لكل فرد؛ على الدولة واجب توفير مسار تطور أساسي وضمان موارد لكل كائن حي |
| المادة الخامسة عشرة | يثبت مبدأ الاستدامة؛ يجب أن تراعي جميع التنمية استدامة أصل الكون |
| المواد من السادسة عشرة إلى الخامسة والعشرين | تحدد الحقوق الأساسية للكائنات الحية: حق اختيار التطور، حق الحصول على موارد الزراعة، حق الحماية المتساوية، حق المشاركة في التكافل، حق الحفاظ على الثقافة، حق الإنقاذ والطعن، حق الحرية الشخصية، حق كرامة الشخص، حق حرية العقيدة، حق حرية التعبير |
| المواد من السادسة والعشرين إلى الحادية والثلاثين | تحدد الواجبات الأساسية للكائنات الحية: واجب الالتزام بالقانون، واجب الحفاظ على النظام التكافلي، واجب المساهمة بالعمل، واجب حماية البيئة، واجب احترام حقوق الآخرين، واجب إرشاد المزارعين المبتدئين |
| المادة الثانية والثلاثون | يثبت المجلس التشريعي للمرساة أعلى هيئة سلطة، يتكون من ممثلين عن عشرة آلاف عرق بنسب متوازنة |
| المادة الثالثة والثلاثون | يثبت اللجنة التنفيذية التكافلية أعلى هيئة إدارية |
| المادة الرابعة والثلاثون | يثبت محكمة التكافل أعلى هيئة قضائية، تمارس السلطة القضائية باستقلال |
| المادة الخامسة والثلاثون | يثبت لجنة الرقابة للمرساة هيئة رقابية مستقلة |
| المادة السادسة والثلاثون | يحدد الإجراء التشريعي: يُمرَّر مشروع القانون بأغلبية تزيد على نصف المجلس التشريعي للمرساة |
| المادة السابعة والثلاثون | يحدد إجراء تعديل الدستور: يجب إقراره بأغلبية تزيد على ثلثي المجلس التشريعي للمرساة وموافقة أكثر من نصف الشعب في استفتاء عام |
| المادة الثامنة والثلاثون | يثبت نظام مراجعة دستورية القوانين؛ يحق لمحكمة التكافل إعلان بطلان القوانين المخالفة للدستور |
| المادة التاسعة والثلاثون | يثبت نظام التقاضي الدستوري؛ يحق لجميع الكائنات الحية رفع دعاوى مباشرة وفق الدستور |
| المادة الأربعون | يحدد نظام الحكم الذاتي المحلي؛ تطبق كل منطقة نجمية وكل بُعد الحكم الذاتي في إطار الدستور |
| المادة الحادية والأربعون | يثبت نظام جمهورية عشرة آلاف عرق؛ جميع الأعراق متساوية في الحضارة التكافلية وتطبق الحكم الذاتي الإقليمي |
| المادة الثانية والأربعون | يحدد النظام الاقتصادي للحضارة التكافلية: بالاستناد إلى العقود المرتبطة بالإنتاج، مع تنمية مشتركة لأشكال ملكية متعددة |
| المادة الثالثة والأربعون | يحدد نظام ملكية الدولة لموارد الزراعة وتوزيعها العادل |
| المادة الرابعة والأربعون | يثبت نظام عدالة التعليم، ويضمن لكل كائن حي حق التعليم المتساوي |
| المادة الخامسة والأربعون | يثبت نظام الضمان الطبي الشامل |
| المادة السادسة والأربعون | يثبت نظام ضمان الإسكان، ويضمن لكل كائن حي حق السكن الأساسي |
| المادة السابعة والأربعون | يحدد المبادئ الأساسية للتفاعل عبر الأبعاد؛ يحظر التنقل عبر الأبعاد دون إذن |
| المادة الثامنة والأربعون | يحدد أن النواتج المشروعة للأنشطة الأثرية تقتصر على المعرفة والمعلومات المجردة؛ ويحظر إعادة المادة والطاقة |
| المادة التاسعة والأربعون | يحدد المبادئ الأساسية للارتداد الزمني؛ يجب اتباع مبدأ الملاحظة أولاً ثم التدخل المحدود |
| المادة الخمسون | يحدد أن حق تفسير الدستور يعود لمحكمة التكافل، وحق تعديل الدستور يعود للمجلس التشريعي للمرساة |

## ثالثاً: قانون العمل التكافلي

قانون العمل التكافلي هو القانون الأساسي الذي ينظم علاقات العمل ويحمي حقوق ومصالح العمال، ووُضع على أساس تشريعي هو المادة الثانية والأربعون من الدستور التكافلي.

| رقم المادة | المحتوى الجوهري |
|----------|----------|
| المادة الأولى | الغرض التشريعي: تنظيم علاقات العمل، حماية الحقوق والمصالح المشروعة للعمال، وبناء علاقات عمل متناغمة تكافلية |
| المادة الثانية | نطاق التطبيق: جميع علاقات العمل في كون هنغ يوان، بما فيها العمل المادي وعمل الزراعة والعمل الإبداعي |
| المادة الثالثة | يثبت مبدأ المساواة في التوظيف للعمال؛ يحظر التمييز الوظيفي القائم على العرق أو الجنس أو مستوى الزراعة أو الأصل |
| المادة الرابعة | يثبت مبدأ حرية اختيار العمل؛ يحظر العمل القسري والاستعباد |
| المادة الخامسة | يحدد نظام عقد العمل؛ يجب إبرام عقد عمل كتابي عند إنشاء علاقة عمل |
| المادة السادسة | يحدد الشروط الإلزامية لعقد العمل: مدة العقد، محتوى العمل، الأجر، ساعات العمل، حماية العمل، التأمين الاجتماعي |
| المادة السابعة | يثبت يوم العمل ثماني ساعات ونظام ساعات عمل لا تتجاوز أربعاً وأربعين ساعة أسبوعياً |
| المادة الثامنة | يحدد قيود العمل الإضافي: لا يتجاوز ساعة واحدة يومياً، وثلاث ساعات في الحالات الخاصة، ولا يتجاوز ستاً وثلاثين ساعة شهرياً |
| المادة التاسعة | يحدد معايير أجر العمل الإضافي: أجر العمل الإضافي في أيام العمل 1.5 ضعف، وفي أيام الراحة ضعفان، وفي الأعياد الرسمية ثلاثة أضعاف |
| المادة العاشرة | يثبت نظام ضمان الحد الأدنى للأجور؛ تحدد كل منطقة نجمية معيار الحد الأدنى للأجور وفق ظروفها المحلية |
| المادة الحادية عشرة | يحدد نظام صرف الأجور: يصرف الأجر شهرياً للعامل شخصياً بعملة نقدية، دون اقتطاع أو تأخير بلا سبب |
| المادة الثانية عشرة | يثبت مبدأ التوزيع عملاً أكثر ربحاً أكثر؛ يطبق نظام توزيع يكون التوزيع حسب العمل أساسه وتتعدد فيه أساليب التوزيع |
| المادة الثالثة عشرة | يحدد نظام سلامة وصحة العمل؛ يجب على أصحاب العمل توفير شروط سلامة وصحة عمل مطابقة للمعايير للعمال |
| المادة الرابعة عشرة | يحدد حماية الفئات الخاصة: حماية عمل خاصة للعمال القاصرين والعاملات والعمال ذوي الإعاقة والعمال منخفضي مستوى الزراعة |
| المادة الخامسة عشرة | يثبت نظام التدريب المهني؛ على أصحاب العمل واجب تدريب العمال على المهارات المهنية |
| المادة السادسة عشرة | يحدد حقوق عمل المزارعين: عمل الزراعة محمي بهذا القانون بالتساوي، وتحدد ملكية نتائج الزراعة بالعقد |
| المادة السابعة عشرة | يثبت نظام التأمين الاجتماعي للعمال: تأمين التقاعد، التأمين الطبي، تأمين البطالة، تأمين إصابات العمل، تأمين الأمومة |
| المادة الثامنة عشرة | يحدد نظام مزايا العمال: على أصحاب العمل توفير المزايا اللازمة للعمال |
| المادة التاسعة عشرة | يثبت نظام معالجة منازعات العمل: آلية معالجة رباعية المستويات هي التفاوض والوساطة والتحكيم والتقاضي |
| المادة العشرون | يحدد نظام النقابات؛ يحق للعمال تشكيل النقابات والانضمام إليها وفق القانون لحماية حقوقهم ومصالحهم المشروعة |
| المادة الحادية والعشرون | يحدد نظام العقد الجماعي؛ تمثل النقابات العمال في إبرام العقود الجماعية مع أصحاب العمل |
| المادة الثانية والعشرون | يحدد أن اللوائح الداخلية لصاحب العمل يجب أن تناقشها مؤتمر العمال أو جميع العمال |
| المادة الثالثة والعشرون | يحدد شروط وإجراءات إنهاء عقد العمل |
| المادة الرابعة والعشرون | يحدد نظام التعويض الاقتصادي؛ يدفع أصحاب العمل تعويضاً اقتصادياً عند إنهاء عقد العمل قانونياً |
| المادة الخامسة والعشرون | يحدد نظام تعويضات إنهاء عقد العمل بطرق غير قانونية |
| المادة السادسة والعشرون | يثبت نظام إدارة العمل المؤقت، وينظم تشغيل العمل المؤقت |
| المادة السابعة والعشرون | يحدد القواعد الخاصة للعمل غير المتفرغ |
| المادة الثامنة والعشرون | يحدد نظام الرقابة والتفتيش؛ تقوم الأجهزة الإدارية للعمل بالرقابة والتفتيش على التزام أصحاب العمل بقوانين العمل وفق القانون |
| المادة التاسعة والعشرون | يحدد المسؤولية القانونية: يتحمل أصحاب العمل المخالفون لهذا القانون مسؤولية إدارية ومدنية وجنائية وفق القانون |
| المادة الثلاثون | يحدد تاريخ نفاذ هذا القانون وحق تفسيره |

## رابعاً: قانون حماية المستهلك

قانون حماية المستهلك هو القانون الأساسي الذي يحمي الحقوق والمصالح المشروعة للمستهلكين وينظم سلوك المشغلين الاقتصاديين.

| رقم المادة | المحتوى الجوهري |
|----------|----------|
| المادة الأولى | الغرض التشريعي: حماية الحقوق والمصالح المشروعة للمستهلكين، والحفاظ على النظام الاقتصادي الاجتماعي، وتعزيز التنمية الصحية لاقتصاد السوق التكافلي |
| المادة الثانية | نطاق التطبيق: حماية حقوق ومصالح المستهلكين في كون هنغ يوان عند شراء واستخدام السلع أو تلقي الخدمات لحاجات الحياة اليومية |
| المادة الثالثة | يثبت المبادئ الأساسية للتعامل بين المشغلين والمستهلكين: الطوعية والمساواة والإنصاف وحسن النية |
| المادة الرابعة | يثبت مبدأ حماية الدولة للحقوق والمصالح المشروعة للمستهلكين؛ تتخذ الدولة إجراءات لضمان ممارسة المستهلكين حقوقهم وفق القانون |
| المادة الخامسة | يحدد الحقوق الأساسية التسعة للمستهلكين: حق السلامة، حق المعرفة، حق الاختيار الذاتي، حق التعامل العادل، حق التعويض، حق تكوين الجمعيات، حق اكتساب المعرفة، حق الاحترام، حق الرقابة |
| المادة السادسة | يحدد حق السلامة للمستهلك: يتمتع المستهلك عند شراء واستخدام السلع وتلقي الخدمات بحق عدم المساس بسلامته الشخصية والممتلكات |
| المادة السابعة | يحدد حق المعرفة للمستهلك: يتمتع المستهلك بحق معرفة الحقيقة الكاملة عن السلع التي يشتريها أو يستخدمها والخدمات التي يتلقاها |
| المادة الثامنة | يحدد حق الاختيار الذاتي للمستهلك: يتمتع المستهلك بحق اختيار السلع أو الخدمات بحرية |
| المادة التاسعة | يحدد حق التعامل العادل للمستهلك: يتمتع المستهلك بحق التعامل العادل ويحق له رفض التعاملات الإجبارية |
| المادة العاشرة | يحدد حق التعويض للمستهلك: المستهلك الذي يتعرض لضرر شخصي أو مالي بسبب شراء واستخدام السلع أو تلقي الخدمات يحق له الحصول على تعويض وفق القانون |
| المادة الحادية عشرة | يحدد الواجبات الأساسية للمشغلين: أداء الالتزامات القانونية والمتعاقد عليها، وقبول الرقابة، وضمان السلامة، وتقديم معلومات صحيحة، وإصدار الإيصالات، وضمان الجودة، وتنفيذ الضمانات الثلاث، وعدم التعامل غير العادل، وعدم انتهاك الكرامة الشخصية |
| المادة الثانية عشرة | يحدد واجب ضمان السلامة للمشغلين: يجب على المشغلين ضمان أن السلع أو الخدمات المقدمة منهم تستوفي متطلبات حماية السلامة الشخصية والممتلكات |
| المادة الثالثة عشرة | يحدد واجب الإفصاح عن المعلومات للمشغلين: يجب على المشغلين تقديم معلومات صحيحة عن السلع أو الخدمات للمستهلكين، دون إعلانات كاذبة أو مضللة |
| المادة الرابعة عشرة | يحدد القواعد الخاصة لمنتجات وخدمات الزراعة: يجب أن يمتلك مشغلو طرق الزراعة وأدوات الزراعة والمنتجات الطاقية مؤهلات خاصة، وأن تجتاز المنتجات شهادة السلامة |
| المادة الخامسة عشرة | يحدد تنظيم الشروط النموذجية: لا يجوز للمشغلين استخدام الشروط النموذجية لاستبعاد أو تقييد حقوق المستهلكين، أو للتخفيف من مسؤولية المشغل أو الإعفاء منها |
| المادة السادسة عشرة | يحدد نظام الإرجاع خلال سبعة أيام دون سبب: يحق للمستهلكين الذين يشترون سلعاً بطرق عن بُعد كالشبكة إرجاعها خلال سبعة أيام من تاريخ الاستلام |
| المادة السابعة عشرة | يحدد نظام الضمانات الثلاث: إذا كانت السلع أو الخدمات المقدمة من المشغلين لا تستوفي متطلبات الجودة، يجوز للمستهلكين طلب الإصلاح أو الاستبدال أو الإرجاع وفق اللوائح الوطنية |
| المادة الثامنة عشرة | يحدد نظام التعويض العقابي: إذا قدم المشغلون سلعاً أو خدمات بسلوك احتيالي، يجب عليهم وفق طلب المستهلكين زيادة تعويض الخسائر المتكبدة، ويكون مبلغ الزيادة ثلاثة أضعاف ثمن السلع المشتراة أو تكلفة الخدمات المتلقاة |
| المادة التاسعة عشرة | يحدد منظمات المستهلكين: جمعيات المستهلكين وغيرها من منظمات المستهلكين منظمات اجتماعية تأسست قانوناً للقيام برقابة اجتماعية على السلع والخدمات وحماية الحقوق والمصالح المشروعة للمستهلكين |
| المادة العشرون | يحدد سبل حل نزاعات الاستهلاك: التفاوض مع المشغل، وطلب الوساطة من جمعية المستهلكين، والتظلم لدى الأجهزة الإدارية المختصة، والإحالة إلى التحكيم، ورفع الدعوى أمام المحكمة |
| المادة الحادية والعشرون | يحدد قلب عبء الإثبات في النزاعات: بالنسبة للسلع المعمرة أو الخدمات كالديكور، إذا اكتشف المستهلكون عيوباً خلال ستة أشهر من الاستلام، يتحمل المشغل عبء الإثبات |
| المادة الثانية والعشرون | يحدد المسؤولية الإدارية والجنائية للمشغلين |
| المادة الثالثة والعشرون | يحدد تاريخ نفاذ هذا القانون وحق تفسيره |

## الخلاصة

فهرس المواد القانونية هو خريطة استرشاد لنظام حكم القانون في حضارة التكافل المرساة. من الدستور التكافلي بوصفه القانون الأساس، إلى قانون العمل وقانون حماية المستهلك المنظمين لمعيشة الناس، ثم إلى القوانين المرافقة الخمسة، تشكل جميعها نظاماً قانونياً متكاملاً «بالدستور قائداً، وبالقوانين الأساسية عموداً فقرياً، وبالقوانين المرافقة سنداً». يضمن هذا النظام سير جميع أنشطة الحضارة التكافلية على مسار حكم القانون، ويوفر ضماناً مؤسسياً راسخاً للتقدم المشترك لعشرة آلاف عرق.
