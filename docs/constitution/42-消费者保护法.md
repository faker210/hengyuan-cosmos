# 消费者保护法

| 项目 | 内容 |
|------|------|
| 文档编号 | 42 |
| 所属模块 | 法律体系与治理框架 |
| 核心关键词 | 消费者权利、公平交易、反欺诈、产品责任、共生市场 |

## 一、立法目的与适用范围

《消费者保护法》是锚点共生文明法律体系中的核心法律之一，与《共生劳动法》共同构成经济生活的两大支柱。本法旨在保护衡元宙内一切消费者的合法权益，规范市场交易行为，维护公平、诚信、共生的市场秩序，防止掠夺式商业行为对众生权益的侵害。

本法适用于衡元宙内一切为满足个人或家庭生活需要而购买、使用商品或接受服务的消费者，以及为消费者提供商品或服务的经营者。跨位面交易同样适用本法，但可根据位面差异制定实施细则。

## 二、消费者基本权利

本法确立消费者享有以下九项基本权利：

| 权利 | 内涵 |
|------|------|
| 安全保障权 | 消费者在购买、使用商品和接受服务时享有人身、财产安全不受损害的权利 |
| 知悉真情权 | 消费者有权知悉其购买、使用的商品或接受的服务的真实情况，包括成分、功效、风险等 |
| 自主选择权 | 消费者有权自主选择商品或服务，有权进行比较、鉴别和挑选，拒绝强制交易 |
| 公平交易权 | 消费者有权获得质量保障、价格合理、计量正确等公平交易条件 |
| 依法求偿权 | 消费者因购买、使用商品或接受服务受到人身、财产损害的，享有依法获得赔偿的权利 |
| 结社维权权 | 消费者有权依法成立或加入消费者组织，维护自身合法权益 |
| 获得知识权 | 消费者有权获得有关消费和消费者权益保护方面的知识与信息 |
| 受尊重权 | 消费者在购买、使用商品和接受服务时，享有人格尊严、民族风俗习惯得到尊重的权利 |
| 监督权 | 消费者有权对商品和服务以及消费者权益保护工作进行监督，提出批评与建议 |

## 三、经营者义务

经营者在向消费者提供商品或服务时，应当履行以下义务：

1. **依法经营义务**：经营者必须遵守宪法与法律，在核准的经营范围内从事经营活动。
2. **安全保障义务**：经营者应当保证其提供的商品或服务符合保障人身、财产安全的要求，对可能危及安全的商品和服务应当作出真实说明和明确警示。
3. **真实信息义务**：经营者应当向消费者提供有关商品或服务的真实信息，不得作虚假或引人误解的宣传。修炼类商品与服务必须如实标注功效边界与潜在风险。
4. **质量保证义务**：经营者应当保证在正常使用商品或接受服务的情况下，其提供的商品或服务应当具有的质量、性能、用途和有效期限。
5. **公平交易义务**：经营者不得以格式条款、通知、声明、店堂告示等方式作出排除或限制消费者权利、减轻或免除经营者责任、加重消费者责任等对消费者不公平、不合理的规定。
6. **售后服务义务**：经营者应当按照国家规定或与消费者的约定，承担修理、更换、退货及其他售后服务责任。
7. **保护隐私义务**：经营者应当保护消费者的个人信息与意识数据，未经消费者同意不得收集、使用或泄露。

## 四、争议解决与法律责任

消费者与经营者发生消费者权益争议的，可以通过以下途径解决：

- 与经营者协商和解
- 请求消费者组织调解
- 向有关行政部门投诉
- 根据与经营者达成的仲裁协议提请仲裁机构仲裁
- 向共生法院提起诉讼

经营者违反本法规定，侵害消费者合法权益的，应当承担以下责任：

| 违法行为 | 法律责任 |
|----------|---------|
| 提供缺陷商品或服务造成损害 | 承担赔偿责任，包括医疗费、误工费、残疾赔偿金等 |
| 欺诈行为 | 按照消费者要求增加赔偿，金额为消费者购买商品价款或接受服务费用的三倍 |
| 虚假宣传 | 责令停止违法行为，消除影响，处以罚款 |
| 强制交易 | 责令改正，退还不合理费用，处以罚款 |
| 侵犯消费者隐私 | 承担精神损害赔偿，情节严重的追究刑事责任 |

## 五、消费者组织与社会监督

国家鼓励、支持一切组织和个人对损害消费者合法权益的行为进行社会监督。消费者协会是依法成立的对商品和服务进行社会监督的保护消费者合法权益的社会组织，履行以下职能：

1. 向消费者提供消费信息和咨询服务
2. 参与有关行政部门对商品和服务的监督、检查
3. 就有关消费者合法权益的问题，向有关行政部门反映、查询，提出建议
4. 受理消费者的投诉，并对投诉事项进行调查、调解
5. 对损害消费者合法权益的行为，支持受损害的消费者提起诉讼

## 结语

《消费者保护法》是锚点共生文明市场秩序的守护者。它通过赋予消费者充分权利、约束经营者行为、建立多元争议解决机制，确保市场交易在公平、诚信、共生的轨道上运行，防止商业领域成为掠夺式行为的新温床。
