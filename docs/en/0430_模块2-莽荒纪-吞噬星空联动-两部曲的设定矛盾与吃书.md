Two-book linkage also has a technical lesson: different systems' cosmos models cannot be hard-welded. Manghuang's cosmos is cultivation-style, law-style; Swallowing Starry Sky's is physical, energy-style. The reason Heng Yuan Zhou's plane theory is expandable is that from the start it defines all planes with the same rule framework — new planes are filled in, not welded on. Rule self-consistency matters more than cosmos size. Manghuang's lesson: draw the cosmos however big, rules not self-consistent are still an unfolded empty map.
