## 1. Penjelasan Indeks

Indeks ini memuat semua tiga ratus set sistem kultivasi asal kosmik yang dibuka oleh Peradaban Simbiosis Jangkar, disusun dalam enam kategori, lima puluh set per kategori, dinomori secara berurutan dari 001 hingga 300. Tiga set sistem pertama (Deduksi Iteratif, Siklus Kehidupan, Kontrol Hukum Ruang) adalah "Tiga Dasar Asal", yang merupakan dasar kultivasi semua sistem. Setiap set sistem mencantumkan nomor, nama, dan ringkasan singkat arah inti. Indeks ini adalah alat konsultasi; untuk metode kultivasi terperinci dan pembagian alam setiap sistem, lihat dokumen khusus sistem yang sesuai.
