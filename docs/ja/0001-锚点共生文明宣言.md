# 錨点共生文明宣言

| 項目 | 内容 |
|------|------|
| 文書番号 | 01 |
| モジュール | 総綱と核心設定 |

## 第一節 宣言の歴史的背景

万霊衡锚本源宙（以下「衡元宙」と略称）の長い歴史において、略奪式修練体系は長期にわたり宇宙の秩序を支配してきた。強者は弱者の本源、気運、生命エネルギーを吞噬することで自らの進歩の階梯とし、宗派は修練法门の独占を統治の基盤とし、位面は戦争と奴隷制を拡張の途とした。この体系は短期的には少数の至高強者を生み出したが、長期的には宇宙の進化潜在能力を枯渇させ、文明の断層を頻発させ、万族を衰退させ、宇宙のエントロピー増大を加速させた。

錨点共生文明の誕生は、この歴史的困局への根本的な応答である。本宣言は宣言する：略奪式修練体系の時代は終焉し、共生進化の新時代が開幕した。衡元宙におけるすべての生命は、種族、形態、修練境界の高低を問わず、平等な進化権利を享有する。

## 第二節 宣言の核心的主張

本宣言は以下の不動の核心的主張を確立する：

1. **進化権平等**：すべての生命は自らの進化経路を選択する基本的権利を有し、いかなる組織または個人もいかなる理由をもってこの権利を剥奪または制限してはならない。
2. **反略奪原則**：他の生命の本源またはエネルギーを吞噬、奴隷化、搾取する手段による修練を禁止する；すべての進化は共生循環の基礎の上に構築されなければならない。
3. **体系開放**：三百套の宇宙本源修練体系は万族に無償で開放され、修練法门はもはや少数者の私有財産ではない。
4. **多労多得**：進化成果は個人の付出と一致し、労せずして得る略奪式分配に反対し、平均主義の惰性的分配にも反対する。
5. **自生自長**：各生命の自主的な進化のリズムを尊重し、強制せず、急がせず、同時に必要な環境と資源の支援を提供する。
6. **人人有路**：各生命が自らの特質に適した修練経路を見出せることを確保し、進化体系に見捨てられる個体は存在しない。
7. **万族共進**：進化はゼロサムゲームではなく、万族間の協力と共生は個体の総和を超える集団進化効能を生み出すことができる。

## 第三節 宣言の法理的基礎

本宣言は空虚な道徳的呼びかけではなく、堅実な法理的基礎を有する文明綱領である。その法理的根拠は以下を含む：

| 法理層級 | 根拠 | 説明 |
|----------|------|------|
| 宇宙法則層 | 本源共生法則 | 宇宙本源法則自体が無秩序な略奪ではなく秩序ある共生に傾き、錨点機構はこの法則の顕在化である |
| 文明憲法層 | 共生文明憲章 | 本宣言は憲章の精神的先駆であり、憲章は宣言の主張を実行可能な法律条文に具体化する |
| 機制保障層 | 聯産承包機制と錨点網 | 制度設計を通じて宣言の主張が骨抜きにされないことを確保し、各生命の進化権には実質的な資源と機制の支えがある |

## 第四節 万族に対する宣言の呼びかけ

本宣言は衡元宙におけるすべての種族と生命形態に呼びかける：

- 略奪式修練の古い経路を捨て、共生進化の新しい体系に加わる
- 各自が保有する修練知識と資源を開放し、三百套体系の共同構築と最適化に参与する
- 他の種族の進化選択権を尊重し、自らの基準を他者に押し付けない
- 錨点網の構築と維持に積極的に参与し、宇宙全体の昇維に貢献する
- 進化の過程で倫理的底線を守り、いかなる口実をもって略奪行為を回復しない

## 第五節 宣言の効力と改正

本宣言は錨点共生文明の成立日より効力を発し、衡元宙におけるすべての文明制度の最高精神綱領である。宣言の改正は万族共和議会の三分の二以上の多数の賛成を必要とし、かつ「反略奪、共生を倡ずる」の核心精神に背いてはならない。本宣言の精神に抵触するいかなる法律、制度、修練法门も無効である。

## 結語

錨点共生文明宣言は、衡元宙の歴史において「共生」を核心とし「万族共進」を目標とする最初の文明綱領である。それは一つの旧時代の終焉と一つの新時代の開幕を宣言する。宣言の導きの下、衡元宙は万族共生、宇宙昇維の究極的方向へと進むであろう。
