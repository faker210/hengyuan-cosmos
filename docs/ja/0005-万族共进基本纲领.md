# 万族共進基本綱領

| 項目 | 内容 |
|------|------|
| 文書番号 | 05 |
| モジュール | 総綱と核心設定 |
| キーワード | 万族、共進、種族平等、協同進化、共和 |

## 第一節 万族の定義と範囲

「万族」とは、万霊衡锚本源宙における知覚と進化の潜在能力を備えたすべての生命形態の総称である。「万」は正確に一万の種族を指すのではなく、その多さを極端に表現するものであり、既知と未知のすべての生命形態を包括する。万族の範囲には、以下に限定されないが、人族および各種の類人種族、エネルギー生命、意識体、機械生命、植物型知能生命、奇異生命、位面間混血種族などが含まれる。

共生文明は「生命形態の平等」の原則を堅持し、生命の物質的構成、エネルギーレベル、意識の複雑さを高・低、貴・賎を区分する基準としない。いかなる種族も、その個体の平均修練境界の高低、人口の多寡、歴史の長短にかかわらず、共生文明において平等な地位と権利を享有する。

## 第二節 万族共進の核心理念

万族共進は錨点共生文明の核心目標の一つであり、その基本理念は以下の四点に要約できる：

1. **進化は種族間のゼロサムゲームではない**：一つの種族の進化は他の種族を犠牲にするものではなく、逆に、種族間の協力は相乗的進化効果を生み出すことができる。
2. **すべての種族には独特の進化的優位性がある**：異なる種族は長い進化の中でそれぞれの特質と才能を形成しており、これらの特質は宇宙進化の多様性の貴重な財産である。
3. **後進種族には支援を受ける権利がある**：進化の程度が低い種族に対して、共生文明は教育、資源、技術などの面で支援を提供する義務があり、彼らが自身に適した進化の道を見つけるのを助ける。
4. **先進種族には責任を担う義務がある**：進化の程度が高い種族は共生文明において、錨点の維持、知識の伝承、文明の保護など、より多くの公共的責任を担う。

## 第三節 万族共進の基本原則

| 原則 | 内包 | 具体的要求 |
|------|------|------------|
| 種族平等原則 | すべての種族は法的地位と進化権において一律に平等 | 種族差別を禁止し、公共の職位をすべての種族に開放 |
| 文化尊重原則 | 各種族の文化伝統と生活様式を尊重 | 文化的同化を強制せず、種族文化の伝承と発展を支援 |
| 優位互補原則 | 種族間がそれぞれの優位性を発揮して協力することを奨励 | 種族の特長データベースを構築し、異種族間協力プロジェクトを促進 |
| 後進扶持原則 | 進化の程度が低い種族に追加的な支援を与える | 種族発展基金を設立し、定向的な教育と資源配給を提供 |
| 自治共治原則 | 種族内部の事務は自治、異種族間の事務は共治 | 各族には内部立法権があり、公共事務は共和機関が決定 |
| 紛争平和解決原則 | 種族間の紛争は平和的な方法で解決 | 種族間戦争を禁止し、紛争は錨点法院に仲裁を付託 |

## 第四節 万族共進の実施経路

万族共進はスローガンではなく、以下の具体的な経路を通じて段階的に実現される：

### 4.1 教育共通

異種族間の共生教育体系を構築し、すべての種族の幼体が無料で基礎進化教育を受けられるようにする。教育内容には、三百套修練体系の基礎法門、反略奪倫理、共生文明憲章、宇宙常識などが含まれる。同時に各族の文化教育伝統を尊重し、共通教育のほかに種族特色教育を実施することを許可する。

### 4.2 資源共享

聯産承包機制を通じて、宇宙修練資源を種族人口、進化需要、貢献程度に応じて総合的に分配する。資源が乏しい種族に対しては、錨点網を通じて位面間資源調配を行う。いかなる種族も公共修練資源を独占することを禁止する。

### 4.3 技術共研

異種族間の技術協力研究を奨励し、特に異なる種族の天賦能力と法則工学を結びつけた研究プロジェクトを推進する。共生文明は「万族共研基金」を設立し、異種族間研究チームに資金援助を行う。研究成果は全種族に無料で開放される。

### 4.4 人材流動

種族間の人材障壁を打ち破り、修練者が異なる種族の聚居区間を自由に流動・交流できるようにする。異種族間導師制度を構築し、高級修練者が他の種族の初級修練者を指導できるようにする。

### 4.5 共和参与

万族共和議会は種族人口と貢献度に応じて議席を総合的に分配し、小種族にも発言の渠道があることを確保する。議会の決定は協商一致と多数表決を組み合わせた方式を採用し、種族の根本利益に関わる事項は関連種族の同意を得なければならない。

## 第五節 特殊種族に対する政策

特殊な状況にある種族に対して、共生文明は差別化された政策を採用する：

- **絶滅危惧種族**：種族保護計画を設立し、緊急資源支援と生息地保護を提供し、個体群の回復を助ける
- **奇異生命種族**：奇異生命三類標準化処置フローに従って評価と安置を行い、その進化権が保障されることを確保する
- **位面間混血種族**：その二重種族身分を承認し、二つの種族文化における平等な権利を保障する
- **前略奪種族**：歴史上略奪主義を奉行した種族に対して、倫理改造と体系転化を完了した後、完全に平等な地位を与え、歴史的遡及差別を行わない

## 第六節 万族共進の衡量指標

共生文明は「万族共進指数」を構築し、以下の次元から万族共進の進展を衡量する：

| 次元 | 指標 | 目標 |
|------|------|------|
| 進化カバー率 | 修練体系に接続した種族の割合 | 100% |
| 境界均衡度 | 各族の平均境界の差異係数 | 持続的に縮小 |
| 協作密度 | 異種族間協力プロジェクトの数と深さ | 持続的に増加 |
| 文化活力 | 種族文化の伝承と革新の活発度 | 多元性を維持 |
| 紛争発生率 | 種族間紛争の発生頻度 | 持続的に低下 |

## 結語

万族共進は錨点共生文明の究極目標の一つであり、宇宙全体の昇維の必要条件でもある。共生文明の枠組みの下で、すべての種族が自身に適した進化の道を見つけることができ、すべての種族の独特性が尊重され発揮される。万族共進は差異を消滅させることではなく、差異の中で調和を実現し、多元の中で共生を達成することである。
