## 第一節 憲法の地位と制定の背景

《共生憲法》は万霊衡锚本源宙（衡元宙）内におけるアンカー共生文明の根本大法であり、最高の法的効力を有する。すべての法律、行政法規、地方性法規および自治条例は憲法と抵触してはならない；すべての組織と個人は憲法を根本的活動準則としなければならず、憲法の尊厳を維持し、憲法の実施を保証する責任を負う。

共生憲法はアンカー共生文明が正式に樹立された際に制定され、その核心的目的は根本法のレベルで「反略奪、倡共生」の文明の底色を確立し、アンカー共生文明の核心理念——運命と進化の選択権を衆生に返還し、多労多得、自生自長、人人有路、万族共進——を最高の法的形式で固定し、略奪式制度の復辟を防止することである。

## 第二節 憲法の基本原則

共生憲法は七つの基本原則を確立し、法体系全体の価値の礎を構成する：

| 原則 | 内包 |
|------|------|
| 万族平等原則 | すべての生命形態は、種族、修為、出身を問わず、法律の前に一律に平等である |
| 共生進化原則 | 個体の進化は他の個体または集団の進化権利を損なう代償としてはならない |
| 多労多得原則 | 資源配分は貢献を核心的根拠とし、労なくして得ることと略奪式占有に反対する |
| 自生自長原則 | 各生命の自主的進化選択権を尊重し、強制的同化と思想統制に反対する |
| 人人有路原則 | 国家と文明は各生命に基本的な進化経路と資源保障を提供する義務を有する |
| 現実為基原則 | 法律は現実世界を唯一の真実の基礎とし、虚構設定は法的効力を有しない |
| 持続可能原則 | すべての発展は宇宙本源の持続可能性を兼ね備えなければならず、沢を干して魚を獲ることに反対する |

## 第三節 公民（衆生）の基本権利

共生憲法は衡元宙内のすべての知覚能力を有する生命に以下の基本権利を付与する：

1. **進化選択権**：各生命は修練体系、進化経路と生活様式を自由に選択する権利を有し、いかなる組織と個人も強制的に干渉してはならない。
2. **修練資源獲得権**：各生命は三百套本源修練体系の基礎法門を無料で獲得する権利を有し、聯産承包机制を通じて必要な修練資源支援を獲得することができる。
3. **平等保護権**：各生命は法律適用、資源配分、教育医療などの面で平等な待遇を享有し、種族、修為、出身に基づく差別を禁止する。
4. **共生参与権**：各生命は公共事務の決策と監督に参与する権利を有し、共生ネットワークを通じて意見を表明し、権利を行使することができる。
5. **文化保留権**：各種族と文明は自身の文化伝統、言語文字と風俗習慣を保留する権利を有し、共生文明は文化多様性を尊重する。
6. **救済申訴権**：各生命は権利が侵害された場合、司法体系を通じて救済を獲得する権利を有し、違法行為に対して申訴と告発を行う権利を有する。

## 第四節 基本義務

権利と義務は対等であり、共生憲法は同時に衆生の基本義務を規定する：

1. **憲法と法律を遵守する義務**
2. **共生秩序と公共利益を維持する義務**
3. **法に基づき労働と貢献に参与する義務**（多労多得の対応面）
4. **宇宙本源と生態環境を保護する義務**
5. **他の生命の合法的権利を尊重する義務**
6. **能力の範囲内で初級修練者を指導する義務**（導師ネットワークの法的基礎）

## 第五節 国家（文明）機構の設置

共生憲法は共生文明の統治架构を確立し、「アンカー議事会—共生執行委員会—共生法院」の三権分立と制衡机制を実行する：

- **アンカー議事会**：最高権力機構、万族代表が比例に基づいて構成され、立法権と重大事項決定権を行使する
- **共生執行委員会**：最高行政機構、憲法と法律の執行、日常的統治を担当する
- **共生法院**：最高司法機構、独立して審判権を行使し、違憲審査と重大案件の審理を担当する

さらに、「アンカー監督委員会」を独立した監督機構として設置し、すべての権力機構に対する監督を担当し、権力の濫用と略奪式行為の復活を防止する。

## 第六節 憲法の改正と保障

共生憲法の改正はアンカー議事会の三分の二以上の多数を経て可決され、かつ国民投票の半数以上の同意を経て、初めて効力を生じる。この厳格な手続きは根本大法としての憲法の安定性を確保し、短期的利益集団が容易に文明の根基を改竄することを防止する。

憲法の実施保障には以下が含まれる：違憲審査制度（共生法院は憲法に違反する法律を無効と宣言する権限を有する）、憲法訴訟制度（衆生は直接憲法に基づいて訴訟を提起することができる）、憲法宣誓制度（すべての公職人員は就任時に憲法に忠誠を誓わなければならない）。

## 結語

《共生憲法》はアンカー共生文明の法律の礎石であり、反略奪主義の最高宣言でもある。それは「共生」を一種の理念から、実行可能、救済可能、保障可能な法制度に転化し、万族共進のために根本的な法治枠組みを提供した。後続の各部門法はすべて本憲法を立法根拠とする。
