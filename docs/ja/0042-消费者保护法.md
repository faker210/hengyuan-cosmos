# 消費者保護法

| プロジェクト | 内容 |
|--------------|------|
| 文書番号 | 42 |
| 所属モジュール | 法律体系と統治枠組み |
| コアキーワード | 消費者権利、公平取引、反欺瞞、製品責任、共生市場 |

## 第一節 立法目的と適用範囲

《消費者保護法》はアンカー共生文明の法律体系における核心的法律の一つであり、《共生労働法》と共同で経済生活の二大支柱を構成する。本法は衡元宙内のすべての消費者の合法的権益を保護し、市場取引行為を規範化し、公平、誠実、共生の市場秩序を維持し、略奪式商業行為による衆生権益への侵害を防止することを目的とする。

本法は衡元宙内の個人または家庭生活の需要を満たすために商品を購入、使用し、またはサービスを受けるすべての消費者、および消費者に商品またはサービスを提供する経営者に適用される。跨位面取引も同様に本法に適用されるが、位面の差異に応じて実施細則を制定することができる。

## 第二節 消費者の基本権利

本法は消費者が以下の九つの基本権利を享有することを確立する：

| 権利 | 内包 |
|------|------|
| 安全保障権 | 消費者は商品を購入、使用し、サービスを受ける際に、人身、財産の安全が損なわれない権利を享有する |
| 真情知悉権 | 消費者は購入、使用する商品または受けるサービスの真実の状況を知悉する権利を有し、成分、効能、リスクなどを含む |
| 自主選択権 | 消費者は自主的に商品またはサービスを選択する権利を有し、比較、鑑別、選別を行う権利を有し、強制取引を拒否することができる |
| 公平取引権 | 消費者は品質保障、価格合理、計量正確などの公平な取引条件を得る権利を有する |
| 依法求償権 | 消費者は商品の購入、使用またはサービスの受領により人身、財産の損害を受けた場合、依法により賠償を得る権利を享有する |
| 結社維権権 | 消費者は依法により消費者組織を結成または加入し、自身の合法的権益を維持する権利を有する |
| 獲得知識権 | 消費者は消費および消費者権益保護に関する知識と情報を得る権利を有する |
| 受尊重権 | 消費者は商品を購入、使用し、サービスを受ける際に、人格尊厳、民族風俗習慣が尊重される権利を享有する |
| 監督権 | 消費者は商品とサービスおよび消費者権益保護活動に対して監督を行い、批評と提案を行う権利を有する |

## 第三節 経営者の義務

経営者は消費者に商品またはサービスを提供する際に、以下の義務を履行しなければならない：

1. **依法経営義務**: 経営者は憲法と法律を遵守しなければならず、核准された経営範囲内で経営活動を行わなければならない。
2. **安全保障義務**: 経営者は提供する商品またはサービスが人身、財産の安全保障の要求に適合することを保証しなければならず、安全を危険にさらす可能性のある商品とサービスについては真実の説明と明確な警示を行わなければならない。
3. **真実情報義務**: 経営者は消費者に商品またはサービスに関する真実の情報を提供しなければならず、虚偽または誤解を招く宣伝をしてはならない。修練類の商品とサービスは効能の境界と潜在的リスクを真実に標記しなければならない。
4. **品質保証義務**: 経営者は商品を正常に使用し、またはサービスを受ける状況において、提供する商品またはサービスが有すべき品質、性能、用途と有効期限を有することを保証しなければならない。
5. **公平取引義務**: 経営者は格式条項、通知、声明、店堂告示などの方式で、消費者の権利を排除または制限し、経営者の責任を軽減または免除し、消費者の責任を加重するなど、消費者に不公平、不合理な規定をしてはならない。
6. **アフターサービス義務**: 経営者は国家の規定または消費者との約定に従い、修理、交換、返品およびその他のアフターサービスの責任を負わなければならない。
7. **プライバシー保護義務**: 経営者は消費者の個人情報と意識データを保護しなければならず、消費者の同意なしに収集、使用または漏洩してはならない。

## 第四節 紛争解決と法律責任

消費者と経営者の間で消費者権益紛争が発生した場合、以下のルートで解決することができる：

- 経営者と協議和解する
- 消費者組織に調停を請求する
- 関係行政部門に苦情を申し立てる
- 経営者と達成した仲裁協定に基づいて仲裁機構に仲裁を申請する
- 共生法院に訴訟を提起する

経営者が本法の規定に違反し、消費者の合法的権益を侵害した場合、以下の責任を負わなければならない：

| 違法行為 | 法律責任 |
|----------|----------|
| 欠陥商品またはサービスを提供して損害を与えた | 賠償責任を負い、医療費、休業損害賠償、障害賠償金などを含む |
| 欺瞞行為 | 消費者の要求に従って賠償を増額し、金額は消費者が購入した商品の価格または受けたサービスの費用の三倍とする |
| 虚偽宣伝 | 違法行為の停止を命じ、影響を除去し、罰金を科す |
| 強制取引 | 是正を命じ、不合理な費用を返還し、罰金を科す |
| 消費者のプライバシーを侵害した | 精神的損害賠償を負い、情状が深刻な場合は刑事責任を追及する |

## 第五節 消費者組織と社会監督

国家はすべての組織と個人が消費者の合法的権益を損なう行為に対して社会監督を行うことを奨励、支援する。消費者協会は依法により設立され、商品とサービスに対して社会監督を行い、消費者の合法的権益を保護する社会組織であり、以下の職能を履行する：

1. 消費者に消費情報とコンサルティングサービスを提供する
2. 関係行政部門の商品とサービスに対する監督、検査に参与する
3. 消費者の合法的権益に関する問題について、関係行政部門に反映、照会し、提案を行う
4. 消費者の苦情を受理し、苦情事項について調査、調停を行う
5. 消費者の合法的権益を損なう行為に対し、損害を受けた消費者が訴訟を提起することを支援する

## 結語

《消費者保護法》はアンカー共生文明の市場秩序の守護者である。それは消費者に十分な権利を付与し、経営者の行為を拘束し、多元的な紛争解決メカニズムを構築することにより、市場取引が公平、誠実、共生の軌道で運行されることを確保し、商業分野が略奪式行為の新たな温床となることを防止する。
