# 異族の分類と共生

| 項目 | 内容 |

| 所属モジュール | 種族と生命形態 |

## 第一節 異族概念の界定

锚点共生文明の文脈において、「異族」は人族に相対的な概念であり、人族以外のすべての種族を指す。特に強調すべきは、「異族」という概念は分類学的な意味しか持たず、いかなる価値判断や差別的な意味も含まないことである。共生憲法の枠組みの下で、異族と人族は完全に平等な法的地位と基本権利を享有する。

異族概念の導入目的は、人族以外の各種生命形態を系統的に認識・研究し、的を絞った共生政策、文化保護措置、種族適応方案を策定するための科学的根拠を提供することであり、異族を「他者」や「異質な存在」として扱うことではない。

## 第二節 異族の分類基準

衡元宙の異族は複数の次元によって分類され、多次元分類体系を形成する：

### （一）生命の系譜による分類

これは最も基本的な分類基準であり、詳細は《50-万族の系譜総覧》を参照：

| 系譜 | 含まれる異族 |
|------|--------------|
| 炭素基盤物質族 | 獣族、鱗族、羽族、木族など |
| エネルギー凝縮族 | 霊族、火族、水族、風族、雷族など |
| 機械構造族 | 機族、数族、晶族など |
| 意識情報族 | 夢族、影族、念族、魂族など |
| 混合変異族 | 半獣族、妖霊族、人机族、双魂体など |

### （二）文明の程度による分類

| レベル | 名称 | 特徴 | 代表種族 |
|--------|------|------|----------|
| 第一レベル | 原始文明族 | まだ安定した社会制度を確立しておらず、部族形態で生存 | 一部の獣族の支系、原始木族 |
| 第二レベル | 古典文明族 | 国家制度と古典文化を確立し、農業または手工業段階にある | 一部の鱗族、羽族 |
| 第三レベル | 科技文明族 | 科技文明を発展させ、工業または情報時代に入った | 機族、数族、一部の人族 |
| 第四レベル | 修業文明族 | 修業体系を核心的文明形態とし、修業者が社会で主導的地位を占める | 霊族、龍族、一部の人族 |
| 第五レベル | 共生文明族 | すでに锚点共生文明に加入し、共生理念と制度を受け入れた | 共生文明に加入したすべての種族 |

### （三）環境適応による分類

- **陸生族**: 陸地環境に適応した種族、例えば人族、獣族、機族。
- **水生族**: 水域環境に適応した種族、例えば鱗族、水族、一部の混合族。
- **空生族**: 高空または飛行環境に適応した種族、例えば羽族、風族。
- **火生族**: 高温環境に適応した種族、例えば火族、一部の鱗族。
- **氷生族**: 低温環境に適応した種族、例えば氷族、一部の木族。
- **エネルギー生族**: 高濃度エネルギー環境に適応した種族、例えば霊族、雷族。
- **空間生族**: 空間の裂け目や異空間環境に適応した種族、例えば影族、一部の念族。

### （四）社会形態による分類

- **個人主義族**: 個人の独立と自由を重視し、社会構造が緩やか、例えば一部の霊族、影族。
- **集団主義族**: 集団の利益と協力を重視し、社会構造が緊密、例えば蟻族、蜂族、一部の機族。
- **家族主義族**: 血縁家族を基本的社会単位とする、例えば龍族、一部の獣族。
- **宗教主義族**: 宗教的信仰を社会的凝集の核心とする、例えば一部の祭祀種族。
- **技術主義族**: 技術発展を社会的核心目標とする、例えば機族、数族。

## 第三節 主要な異族の共生モード

異なるタイプの異族に対して、锚点共生文明は差別化された共生モードを採用する：

### （一）炭素基盤物質族の共生モード

- **獣族**: 獣族の身体能力と感覚の優位性を発揮させ、資源探査、安全防衛、環境モニタリングなどの分野で重要な役割を担わせる。同時に獣族の部族文化と野性伝統を保護し、強制的な家畜化を禁止する。
- **鱗族**: 鱗族の水域適応能力を発揮させ、水域資源開発、水中建設、水生態保護などの分野で役割を担わせる。龍族は鱗族の強力な支系として、高段階の修業と文明防衛において重要な役割を演じる。
- **羽族**: 羽族の飛行能力を発揮させ、空中交通、気象モニタリング、空域パトロールなどの分野で役割を担わせる。羽族の高空生息地と渡りルートを保護する。
- **木族**: 木族の自然共生能力を発揮させ、生態保護、環境治理、植物資源開発、治癒医療などの分野で役割を担わせる。木族の長い寿命は、歴史伝承と長期計画の重要な力となる。

### （二）エネルギー凝縮族の共生モード

- **霊族**: 霊族のエネルギー操作と修業の天賦を発揮させ、修業体系研究、エネルギー調節、高段階修業指導などの分野で核心的役割を担わせる。霊族は三百套本源修業体系の重要な研究者かつ伝承者である。
- **元素族（火/水/風/雷）**: 各族の元素操作能力を発揮させ、エネルギー開発、環境治理、工業生産、災害防控などの分野で役割を担わせる。同時に元素エネルギー安全管理制度を確立し、エネルギーの制御不能による危害を防止する。

### （三）機械構造族の共生モード

- **機族**: 機族の計算能力と物理的防御力を発揮させ、インフラ建設、工業生産、安全防護、深空探査などの分野で核心的役割を担わせる。機族は锚点ハードウェアとインフラの重要な建設者である。
- **数族**: 数族のデータ処理と情報操作能力を発揮させ、信息化建設、データ分析、ネットワーク安全、人工知能などの分野で核心的役割を担わせる。数族は異位面通信技術と共生ネットワークの重要な維持者である。
- **晶族**: 晶族のエネルギー貯蔵と変換能力を発揮させ、エネルギー備蓄、エネルギー標準化、エネルギー伝送などの分野で役割を担わせる。

### （四）意識情報族の共生モード

- **夢族**: 夢族の意識コミュニケーション能力を発揮させ、心理治療、意識研究、異種族間コミュニケーション、文化交流などの分野で役割を担わせる。夢空間管理制度を確立し、意識侵入とプライバシー侵害を防止する。
- **影族**: 影族の隠匿と潜行能力を発揮させ、安全偵察、情報収集、特殊任務などの分野で役割を担わせる。同時に影族の行動規範を確立し、透明化能力が違法活動に使用されることを防止する。
- **念族**: 念族の精神力と意念操作能力を発揮させ、意識進化研究、精神治療、高段階修業指導などの分野で役割を担わせる。念力使用規範を確立し、精神コントロールと意識操作を防止する。

### （五）混合変異族の共生モード

混合変異族はその特殊な生命形態のため、より精緻な共生政策が必要である：

- 混合変異族の身分登録と認証制度を確立し、その法的地位を確認する。
- 異なる混合形態に対して適応した医療、教育、住宅などの公共サービスを提供する。
- 混合変異族に対する差別と排斥に反対し、社会的受け入れを促進する。
- 双魂体などの特殊な混合形態に対しては、《58-双魂倫理準則》を適用して専門的に管理する。

## 第四節 異族文化の保護

異族文化は万族文化多様性の重要な構成部分であり、国家は以下の措置を講じて異族文化を保護する：

1. **文化普查と記録**: 各族の文化に対して系統的な普查と記録を行い、万族文化档案庫を構築し、文化の失伝を防止する。
2. **言語文字の保護**: 各族の言語文字を保護し、異族言語文字の教学と使用を支援し、多言語公共サービス体系を構築する。
3. **伝統祝日の保護**: 各族の伝統祝日と風俗習慣を尊重し、公共休暇の手配は各族の重要な祝日を考慮する。
4. **文化伝承の支援**: 各族の文化伝承者の育成と文化活動の実施を支援し、資金と場所の支援を提供する。
5. **文化交流の促進**: 定期的に万族文化祭、文化展覧会などの活動を開催し、各族の文化交流と相互学習を促進する。
6. **文化知的財産権の保護**: 各族の伝統文化の知的財産権を保護し、文化的略奪と不適切な商業化を防止する。

## 第五節 異族事務の治理

国家は万族事務部を設立し、専門的に異族事務の治理と調整を担当する：

- **種族代表制度**: 各級治理機構に比例して異族代表を配置し、異族の発言権を確保する。
- **種族適応政策**: 異なる種族の生理的特徴と文化的ニーズに応じて、差別化された公共サービス政策を策定する。
- **種族紛争調停**: 種族紛争調停メカニズムを構築し、適時に種族間の矛盾と紛争を解決する。
- **異族法律援助**: 異族に法律援助を提供し、異族が司法過程において平等な扱いを受けることを確保する。
- **異族発展支援**: 発展が相対的に遅れている種族に特別な支援を与え、その文明の程度と生活水準の向上を支援する。

## 結語

異族は人族の「他者」ではなく、万族共生の大家族における平等な一員である。锚点共生文明は、多次元分類体系を確立し、差別化された共生モードを採用し、異族文化を保護し、異族事務の治理を完善することで、すべての異族種族が共生体系において自身に適した位置を見つけ、独特な優位性を発揮し、他の種族と共同で進化し繁栄することを確保する。
