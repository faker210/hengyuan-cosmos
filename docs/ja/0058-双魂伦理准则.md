# 双魂倫理準則

## 第一節 双魂倫理問題の提起

双魂倫理問題は、锚点共生文明が闇の置換体（詳細は『57-闇の置換体の起源と本質』を参照）に直面する際に答えなければならない根本的な倫理問題である。一つの身体の中に二つの独立した魂——元宿主魂と闇の置換魂——が存在する場合、一連の深刻な倫理問題が生じる：

- 二つの魂はいずれも独立した人格権を有するか？
- 元宿主魂の権利は闇の置換魂の権利に優先するか？
- 元宿主魂を保護するために闇の置換魂を消滅させることは倫理的か？
- 二つの魂の利益が衝突した場合、どのようにバランスを取るべきか？
- 社会は闇に置換された元宿主魂を救うために資源を投入する義務があるか？
- 闇の置換魂には「生存権」があるか？

これらの問題には単純な答えはなく、実践を指導するための体系的な倫理準則を確立する必要がある。『双魂倫理準則』はまさにこれらの問題に応えるために制定された規範的文書であり、闇の置換体の識別、治療と処置の倫理的基礎である。

## 第二節 双魂倫理の基本原則

双魂倫理準則は、双魂問題を処理するための価値の礎として、以下の六つの基本原則を確立する：

| 原則 | 内包 |
|------|------|
| 魂の尊厳原則 | 独立した意識を持つすべての魂は生まれながらの尊厳を享有し、随意に消滅または奴隷化されてはならない |
| 元宿主優先原則 | 双魂の衝突において、元宿主魂の合法的権利は闇の置換魂の権利に優先する、元宿主は身体の合法的所有者であるため |
| 最小傷害原則 | 双魂問題を処理する際には、すべての関係者に対する傷害が最も小さい方案を選択し、可能な限り魂の消滅を回避すべきである |
| 比例原則 | 採用される措置は双魂体のリスクの程度に適合すべきであり、過剰な処置は禁止される |
| インフォームド・コンセント原則 | 元宿主魂が意思を表明できる場合、元宿主の身体と魂に関わる重大な決定には元宿主の同意を得るべきである |
| 尽力救済原則 | 社会は合理的な範囲内で闇に置換された元宿主魂を救うために尽力する義務があり、安易に放棄してはならない |

## 第三節 双魂の人格権認定

双魂倫理の首要問題は二つの魂の人格権認定である。本準則は以下の認定ルールを確立する：

### （一）元宿主魂の人格権

元宿主魂は身体の合法的所有者であり、その人格権は完全に承認され保護される：

1. 元宿主魂は共生憲法が付与するすべての基本権利を享有し、生命権、身体権、健康権、人格尊厳権などを含む。
2. 元宿主魂は自分の身体に対して最終的な決定権を有し、意思を表明できる場合、身体に関わるいかなる重大な処置も元宿主の同意を得なければならない。
3. 元宿主魂の財産権、身分権、社会関係などの合法的権益は法律によって保護され、闇に置換されたことによって喪失しない。
4. 元宿主魂は社会の救助と支援を受ける権利があり、浄化治療、法律扶助、心理カウンセリングなどを含む。
5. 元宿主魂は深度抑圧されている場合でも、その人格権は依然として存在し、死亡宣告または権利剥奪されてはならない。

### （二）闇の置換魂の人格権

闇の置換魂の人格権認定は比較的複雑であり、本準則は「限定的承認」の立場を取る：

| 発展段階 | 人格権認定 | 権利範囲 |
|----------|-----------|----------|
| エネルギー侵食期（第一段階） | 独立した人格を有しない | まだ独立した魂を形成しておらず、独立した人格権はない |
| 魂汚染期（第二段階） | 独立した人格を有しない | 依然として元宿主魂の汚染状態であり、独立した人格権はない |
| 双魂形成期（第三段階） | 限定的人格権 | 初步的な独立した意識を有し、基本的な魂の尊厳権を享有するが、身体控制権と完全な公民権は享有しない |
| 闇主導期（第四段階） | 限定的人格権 | 完全な独立した意識を有し、魂の尊厳権と尊重されて扱われる権利を享有するが、その危険性のため、権利は必要な制限を受ける |
| 完全置換期（第五段階） | 完全人格権（但し敵対的存在として） | 元宿主は既に消亡し、闇の魂は身体の唯一の魂となり、完全な人格権を有するが、その敵対的行動のため、消滅を含む強制措置を法律に基づいて採ることができる |

### （三）限定的人格権の具体的内容

闇の置換魂が第三、第四段階で享有する限定的人格権には以下が含まれる：

1. **魂の尊厳権**：侮辱、虐待、拷問の方法で扱われてはならず、管控と処置においても基本的な尊重を維持すべきである。
2. **無痛消滅権**：最終的に闇の置換魂を消滅させることが決定された場合、無痛で迅速な方法を採用し、その苦痛を減らすべきである。
3. **表現権**：安全で制御可能な条件下で、闇の置換魂は自分の意思と立場を表明する権利があるが、その表現には法的拘束力はない。
4. **聴取権**：闇の置換魂に関わる重大な決定を行う際には、合理的な範囲内でその意見を聴取すべきである。

闇の置換魂は以下の権利を享有しない：身体控制権、自由行動権、公民政治権利、財産所有権（元宿主の財産は元宿主の所有）、繁殖権（闇の血脈の伝播を防止するため）。

## 第四節 双魂利益衝突のバランスルール

元宿主魂と闇の置換魂の利益が衝突した場合、以下のルールに従ってバランスを取る：

### （一）衝突類型とバランスルール

| 衝突類型 | バランスルール |
|----------|---------------|
| 生存権衝突（一方の生存が他方の消亡を条件とする） | 元宿主魂の生存権が優先し、共存不可能な場合には元宿主の生存保護を優先する |
| 身体控制権衝突 | 元宿主魂は身体に対して最終的な控制権を有し、闇の魂の身体控制権は厳格に制限される |
| 表現権衝突 | 元宿主魂の表現には法的拘束力があり、闇の魂の表現は参考としてのみ機能する |
| 財産権衝突 | 身体と財産は元宿主の所有であり、闇の魂は財産権を享有しない |
| 治療選択権衝突 | 元宿主魂は浄化治療を受けるかどうかを選択する権利があり、闇の魂は阻止する権利がない |
| 処置方式衝突 | 闇の魂の消滅に関わる処置において、元宿主魂の意思は決定的な役割を果たす（但し倫理審査を経なければならない） |

### （二）元宿主意思の尊重と制限

元宿主魂が意思を表明できる場合、元宿主の意思を十分に尊重すべきであるが、以下の場合は例外である：

1. 元宿主の意思が明らかに公共の安全または他人の合法的権益を損なうものである場合、保護されない。
2. 元宿主が闇の魂の影響下で行った非真実の意思表示には法的効力がない。
3. 元宿主が自発的に闇の魂との融合を選択した場合、厳格な倫理審査とリスク評価を経て、融合後の存在が社会に脅威を構成しないことを確認しなければならない。
4. 元宿主が自発的に治療放棄と闇の魂の完全置換の受け入れを選択した場合、社会は介入と勧告を行うべきであるが、元宿主が完全に清醒で繰り返し確認した場合、最終的には元宿主の自主決定権を尊重すべきである（これは倫理上のグレーゾーンであり、個別審査が必要である）。

## 第五節 双魂倫理審査メカニズム

双魂問題の処理が倫理準則に適合することを確保するため、国家は双魂倫理審査メカニズムを確立する：

### （一）倫理審査委員会

- **構成**：倫理学者、法学者、生命科学者、修練者、異族代表、社会公衆代表から構成され、そのうち闇の置換体の研究または治療経験を有する専門家は三分の一以上を占める。
- **職責**：双魂に関わる重大な倫理問題の審査と裁決を行い、闇の魂の消滅決定、双魂融合の承認、元宿主意思の効力認定などを含む。
- **独立性**：倫理審査委員会は独立して職権を行使し、行政機関と個人の干渉を受けない。
- **手続き**：審査は聴聞制を実施し、元宿主（表明可能な場合）、治療チーム、家族、社会代表など各方の意見を聴取した後に裁決を行う。

### （二）倫理審査を経なければならない事項

以下の事項は双魂倫理審査委員会の審査承認を経て初めて実施できる：

1. 第三、第四段階の闇の置換体に対して闇の魂消滅の処置を実施すること。
2. 闇の置換体に対して双魂融合手術を実施すること。
3. 闇の置換体に対して魂分離手術を実施すること。
4. 元宿主の意思が治療放棄である闇の置換体に対して最終的な処置決定を行うこと。
5. 闇の置換体に対して元宿主魂の損傷を引き起こす可能性のある治療方案を実施すること。
6. 闇の置換体に対して魂に関わる科学研究を行うこと。
7. 双魂の重大な倫理問題に関わるその他の事項。

## 第六節 双魂体の社会権利と義務

### （一）社会権利

元宿主魂が尚存する場合、双魂体（闇の置換体）は以下の社会権利を享有する：

1. 基本的な生活保障と医療救治を受ける権利。
2. 法律扶助と倫理カウンセリングを受ける権利。
3. 安全で制御可能な条件下で親友と接触する権利。
4. 教育と文化活動を受ける権利（隔離施設内）。
5. 処置決定に対して申訴と再審を請求する権利。

### （二）社会義務と制限

双魂体は同時に以下の義務と制限を負担する：

1. 隔離管控と治療を受ける義務。
2. 他の生命体を攻撃または感染させない義務（違反者はより厳格な管控を受ける）。
3. 識別評価とモニタリングに協力する義務。
4. 行動の自由は厳格に制限され、治癒前に隔離施設を離れてはならない。
5. 修練、闇エネルギーの伝播など置換を悪化させる可能性のある活動に従事してはならない。

## 第七節 双魂倫理の前沿争議

双魂倫理の分野には依然として共通認識に達していないいくつかの前沿争議が存在し、実践の中で継続的に模索する必要がある：

1. **闇の魂の「原罪」問題**：闇の置換魂は誕生時から破壊的であるが、これはそれが生まれながらに「悪」であることを意味するか？「善良」な闇の魂が存在する可能性はあるか？
2. **魂融合の倫理的正当性**：双魂融合によって生まれた新しい魂は元宿主でも闇の魂でもないが、この「第三の存在」の倫理的地位はどのように認定されるべきか？
3. **資源投入の限度**：社会は闇の置換体の中の元宿主魂を救うためにどれだけの資源を投入すべきか？救済コストが極めて高く成功率が極めて低い場合、依然として尽力救済の義務があるか？
4. **闇の魂の改造可能性**：教育、感化、エネルギー改造などの方法を通じて闇の魂を非破壊的な存在に改造できるか？できる場合、改造後の闇の魂は完全な人格権を獲得すべきか？
5. **予防とプライバシーのバランス**：闇の置換体の発生を予防するため、生命体の深淵エネルギー暴露をモニタリングできるか？このモニタリングは魂のプライバシーを侵害するか？

これらの争議問題は双魂倫理研究機関によって継続的に研究され、倫理審査委員会は個別のケースで具体的な状況に応じて裁決を行い、関連する結論は本準則を継続的に更新する。

## 結語

双魂倫理準則は锚点共生文明の生命倫理の深度ある体現である。それは魂の尊厳、元宿主優先、最小傷害などの基本原則を確立し、双魂の人格権の境界を認定し、利益衝突のバランスルールと倫理審査メカニズムを確立することで、闇の置換体の統治に堅実な倫理的基礎を提供する。双魂倫理の核心精神は：最も危険な敵に直面しても、生命の尊厳への堅持を放棄しない；最も差し迫った安全の脅威の下でも、倫理の底線を越えない。これこそが共生文明が略奪文明と区別される根本的な標識である。
