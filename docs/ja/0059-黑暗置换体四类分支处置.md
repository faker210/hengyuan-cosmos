# 闇の置換体の四つの分岐処置

| 項目 | 内容 |
|------|------|
| 文書番号 | 59 |
| モジュール | 种族と生命形態 |
| 核心キーワード | 共生融合、分離配置、封印監視、消滅、分岐処置 |

## 第一節 分岐処置の全体構造

闇の置換体の処置は、アンカー共生文明の生命統治における最も複雑な分野である。奇特生命と奇特エネルギーの三類処置プロセスとは異なり、闇の置換体は双魂共存という特殊な構造（詳細は「57-闇の置換体の起源と本質」を参照）を伴うため、より精緻な分岐処置計画が必要である。「58-双魂倫理準則」が定めた倫理原則に基づき、闇の置換体の発展段階、元宿主の霊魂状態、闇霊魂の特徴、リスクレベルを総合して、闇の置換体の処置を四つの分岐に分ける：共生融合型、分離配置型、封印監視型、消滅型。

四つの分岐処置の選択は、以下の意思決定ロジックに従う：

| 意思決定要素 | 考慮点 |
|--------------|--------|
| 発展段階 | 第一段階から第三段階までは救済を優先、第四段階は慎重に評価、第五段階は元宿主が既に死亡 |
| 元宿主の霊魂状態 | 元宿主の霊魂がまだ存在するか、意志を表明できるか、回復の可能性があるか |
| 闇霊魂の特徴 | 闇霊魂にコミュニケーションの可能性があるか、更生の余地があるか、破壊性の程度 |
| リスクレベル | 公共の安全と他人の権利に対する脅威の程度 |
| 倫理審査の結論 | 双魂倫理審査委員会の審査意見と決定 |
| 元宿主の意志 | 元宿主の霊魂が意志を表明できる状態での選択 |

## 第二節 第一類：共生融合型処置

共生融合型処置は四つの分岐の中で最も積極的かつ建設的な処置方法であり、元宿主の霊魂と闇霊魂が和解を達成し霊魂融合を実現する可能性のある闇の置換体に適用される。

### （一）適用条件

共生融合型処置は、以下の条件を同時に満たさなければならない：

1. 闇の置換体が第三段階（双魂形成期）または第四段階の初期（闇支配期の初期）にあり、元宿主の霊魂がまだ存在し、一定の自主意識を有している。
2. 元宿主の霊魂が明確に闇霊魂との融合を試みる意志を表明しており、その意志が真実かつ自主的なものと認定されている。
3. 闇霊魂が一定のコミュニケーション能力を有し、純粋な破壊的特徴を示さず、融合を受け入れる可能性がある。
4. リスクレベルの評価が第二級（中リスク）以下であり、融合プロセスが公共の安全に対して制御不能な脅威を構成しない。
5. 双魂倫理審査委員会の承認を得ている。

### （二）処置目標

元宿主の霊魂と闇霊魂を導いて和解を達成させ、二つの霊魂の有機的融合を実現し、元宿主の記憶・人格と闇の力を融合させた新しい霊魂を形成する。融合後の新しい霊魂は元宿主の公民身分と合法的権利を保持しつつ、闇エネルギーの制御能力を獲得し、共生文明の特別な成員となる。

### （三）処置ステップ

| ステップ | 名称 | 具体的内容 | 責任機関 |
|----------|------|------------|----------|
| 第一ステップ | 倫理審査 | 双魂倫理審査委員会が融合計画に対して全面的な審査を行い、倫理原則に適合していることを確認する | 双魂倫理審査委員会 |
| 第二ステップ | コミュニケーション指導 | 制御された環境で、専門の霊魂指導者が元宿主の霊魂と闇霊魂のコミュニケーションを支援し、相互理解を促進する | 霊魂治療センター + 修行者 |
| 第三ステップ | 和解交渉 | 二つの霊魂を導いて、融合後の身分・記憶・能力・行動規則などについて和解協定を締結する | 霊魂治療センター + 法律顧問 |
| 第四ステップ | 融合準備 | 融合前の身体調養・エネルギー平衡・心理構築などの準備作業を行う | 医療チーム + 修行指導者 |
| 第五ステップ | 霊魂融合 | 高レベル修行者と霊魂治療師の共同支援のもと、霊魂融合の手術・儀式を実施する | 高レベル修行者 + 霊魂治療師 |
| 第六ステップ | 融合後安定化 | 融合後の新しい霊魂に対して安定化治療を行い、霊魂の完全性と身体の適応性を監視する | 医療チーム + 監視チーム |
| 第七ステップ | 身分確認 | 融合後の新しい霊魂の身分を確認し、元宿主の公民身分を保持し、身分アーカイブを更新する | 登記管理機関 + 生命管理局 |
| 第八ステップ | 統合支援 | 融合後の個人に対して心理カウンセリング・修行指導・社会統合などの支援サービスを提供する | 万族事務部 + コミュニティ |
| 第九ステップ | 長期監視 | 融合した個人に対して5年以上の長期的な追跡監視を行い、融合の安定性と社会適応性を評価する | 生命管理局 + コミュニティ |

### （四）融合後の管理

融合後の個人は元宿主の公民身分を保持するものの、特別な管理を受ける必要がある：

- **エネルギー制御**：融合した個人による闇エネルギーの使用は厳格に制御され、定期的にエネルギー検出を行わなければならず、公共の場での闇エネルギーの使用は禁止される。
- **行動監視**：融合した個人は定期的に自己の行動状況を生命管理局に報告しなければならず、コミュニティの監視と援助を受ける。
- **修行制限**：融合した個人は闇属性を悪化させる可能性のある修行法を修練してはならず、修行計画は承認を得なければならない。
- **緊急計画**：融合した個人の闇が制御不能になった場合の緊急計画を策定し、制御不能の兆候が現れたら直ちに制御を開始する。
- **退出メカニズム**：融合後に深刻な不安定または持続的な危険行動が現れた場合、再評価して他のタイプの処置に転換することができる。

### （五）融合失敗の処置

霊魂融合には失敗のリスクがあり、融合失敗の処置計画：

- **融合中断**：融合プロセス中に深刻な不安定が現れた場合、直ちに融合を中断し、二つの霊魂を融合前の状態に回復させる。
- **不完全融合**：融合後に霊魂の不完全性または人格分裂が現れた場合、後続処理のために分離配置型処置に転換する。
- **融合制御不能**：融合後に新しい霊魂が制御不能な破壊性を示した場合、直ちに封印監視型または消滅型処置に転換する。

## 第三節 第二類：分離配置型処置

分離配置型処置は、元宿主の霊魂と闇霊魂が融合できないが分離可能な闇の置換体に適用され、霊魂分離手術によって二つの霊魂を分離し、別々に配置する。

### （一）適用条件

1. 闇の置換体が第三段階または第四段階にあり、元宿主の霊魂がまだ存在し、回復の可能性がある。
2. 二つの霊魂の融合の試みが失敗したか、融合の条件がない。
3. 技術的評価により霊魂分離が実行可能であり、分離後に元宿主の霊魂が独立して生存できる。
4. 元宿主の霊魂が明確に分離の意志を表明している。
5. 双魂倫理審査委員会の承認を得ている。

### （二）処置目標

霊魂分離手術によって元宿主の霊魂と闇霊魂を分離し、元宿主の霊魂は身体に戻って通常の生活を回復し、闇霊魂は制御と研究のために特別な容器または施設に配置される。

### （三）処置ステップ

| ステップ | 名称 | 具体的内容 | 責任機関 |
|----------|------|------------|----------|
| 第一ステップ | 倫理審査 | 双魂倫理審査委員会が分離計画を審査し、分離の必要性と実行可能性を確認する | 双魂倫理審査委員会 |
| 第二ステップ | 分離準備 | 分離前の身体評価・霊魂状態検出・エネルギー平衡調整などの準備作業を行う | 医療チーム + 霊魂治療師 |
| 第三ステップ | 霊魂分離 | 高レベル修行者と霊魂治療師の支援のもと、霊魂分離手術を実施し、二つの霊魂を身体から分離する | 高レベル修行者 + 霊魂治療師 |
| 第四ステップ | 元宿主の復帰 | 元宿主の霊魂を再び身体に移植し、霊魂の安定化と身体の回復治療を行う | 医療チーム |
| 第五ステップ | 闇の配置 | 分離された闇霊魂を特別な霊魂封じ込め容器に配置し、霊魂封印施設に保管する | 生命管理局 + 技術チーム |
| 第六ステップ | 元宿主の回復 | 元宿主に対して全面的な身体回復・心理治療・修行回復を行い、通常の生活への復帰を支援する | 医療チーム + 心理カウンセラー |
| 第七ステップ | 身分回復 | 元宿主の身分と権利の完全な回復を確認し、身分アーカイブを更新する | 登記管理機関 |
| 第八ステップ | 闇霊魂の管理 | 分離された闇霊魂に対して持続的な監視と研究を行い、その更生または消滅の可能性を探る | 生命管理局 + 研究機関 |

### （四）分離後の闇霊魂の配置

分離された闇霊魂は以下の方法で配置される：

- **霊魂容器**：闇霊魂は特別な霊魂封じ込め容器に配置され、容器にはエネルギーシールド・意識抑圧・安全ロックなどの装置が装備されている。
- **封印施設**：容器は特別な霊魂封印施設に保管され、施設は最高レベルの安全管理を実施する。
- **持続監視**：闇霊魂の意識活動とエネルギー変動に対して24時間持続的な監視を行う。
- **研究利用**：厳格な倫理審査のもと、闇霊魂に対して科学的研究を行うことができ、深淵エネルギーの本質と浄化方法を探る。
- **最終処置**：研究結果とリスク評価に基づき、闇霊魂に対する最終処置の決定を行う——非破壊的存在への更生、長期封印、または浄化による消滅。

### （五）分離のリスクと対処

霊魂分離手術には以下のリスクがあり、対処計画を策定しなければならない：

| リスク | 対処計画 |
|--------|----------|
| 分離プロセス中に元宿主の霊魂が損傷を受ける | 分離前に霊魂の強化を行い、分離中は高レベル修行者が全程で支援する |
| 分離後に元宿主の身体が適応できない | 分離後に全面的な身体回復と霊魂安定化治療を行う |
| 分離プロセス中に闇霊魂が脱走する | 分離は最高レベルの安全施設で実施され、複数の封じ込め装置が装備されている |
| 分離が不完全で、闇エネルギーが残留する | 分離後に深度浄化治療を行い、残留する闇エネルギーを浄化する |
| 分離後に元宿主の霊魂が心理的トラウマを負う | 長期的な心理カウンセリングと精神治療を提供する |

## 第四節 第三類：封印監視型処置

封印監視型処置は、融合も分離もできないが、元宿主の霊魂がまだ存在し直ちに消滅させる条件がない闇の置換体に適用され、封印の手段によってその危険性を制御し、長期的な監視と持続的な評価を行う。

### （一）適用条件

1. 闇の置換体が第四段階（闇支配期）にあり、元宿主の霊魂が深く抑圧されているがまだ死亡していない。
2. 融合と分離のいずれも技術的実行可能性がないか、リスクが高すぎる。
3. 闇の置換体のリスクレベルが第三級（高リスク）であるが、まだ直ちに消滅させる必要がある程度に達していない。
4. 元宿主の霊魂にはまだ微弱な回復の可能性があり、機会を待つための時間と条件が必要である。
5. 双魂倫理審査委員会が封印計画を承認している。

### （二）処置目標

封印の手段によって闇霊魂の力と活動を抑圧し、闇の置換体の危険性を制御すると同時に、元宿主の霊魂が完全に消滅しないよう保護し、長期的な監視の中で回復または処置の時期の熟成を待つ。

### （三）封印方法

闇の置換体の力のレベルと特徴に応じて、以下の封印方法を選択する：

| 封印方法 | 原理 | 適用対象 |
|----------|------|----------|
| エネルギー封印 | 封印陣または封印装置を使用して闇エネルギーの流れと出力を抑圧する | 中下レベルの力の闇の置換体 |
| 空間封印 | 闇の置換体を独立した隔離空間に封印し、外界との接触を遮断する | 高レベルの力または感染性特徴を持つ闇の置換体 |
| 意識封印 | 闇霊魂の意識活動を抑圧し、睡眠または半睡眠状態に保つ | 活発な意識と霊魂攻撃能力を持つ闇の置換体 |
| 多重封印 | 複数の封印方法を同時に使用し、多重防護を形成する | 極めて高いレベルの力または複数の危険特徴を持つ闇の置換体 |
| アンカー封印 | アンカーエネルギーの本源属性を使用して封印し、最も強力な封印方法である | 宇宙級の危険な闇の置換体 |

### （四）処置ステップ

| ステップ | 名称 | 具体的内容 | 責任機関 |
|----------|------|------------|----------|
| 第一ステップ | 倫理審査 | 双魂倫理審査委員会が封印計画を審査し、封印の必要性と適切性を確認する | 双魂倫理審査委員会 |
| 第二ステップ | 封印準備 | 封印陣・装置・空間を準備し、封印に必要なエネルギーと人員を配分する | 技術チーム + 高レベル修行者 |
| 第三ステップ | 制圧制御 | 警備チームの協力のもと、闇の置換体を制圧し、封印プロセス中に事故が発生しないことを確保する | 警備部 + 高レベル修行者 |
| 第四ステップ | 封印実施 | 封印計画に従って封印を実施し、闇霊魂の力と活動を抑圧する | 高レベル修行者 + 封印専門家 |
| 第五ステップ | 封印検証 | 封印の有効性と安定性を検証し、闇の置換体の危険性が制御されたことを確認する | 技術チーム + 監視チーム |
| 第六ステップ | 移送配置 | 封印された闇の置換体を特別な封印監視施設に移送する | 警備部 + 生命管理局 |
| 第七ステップ | 持続監視 | 封印状態に対して24時間持続的な監視を行い、定期的に封印の安定性を検査する | 監視チーム |
| 第八ステップ | 定期再評価 | 半年ごとに全面的な再評価を行い、元宿主の霊魂状態・闇霊魂の特徴・封印の安定性を評価し、処置タイプを調整する可能性があるか判断する | 識別専門家チーム + 倫理審査委員会 |
| 第九ステップ | 封印維持 | 定期的に封印の保守と強化を行い、封印の弱化または損傷を防止する | 封印専門家 + 技術チーム |

### （五）封印監視施設の基準

- **立地**：封印監視施設は地質が安定し、エネルギー環境が安定し、人口がまばらな辺鄙な地域、または独立した隔離次元に位置する。
- **構築**：施設は多重防護構造を採用し、物理的障壁・エネルギー障壁・空間ロックの三層防護を含む。
- **設備**：高精度の封印監視装置・自動強化システム・緊急対応システム・予備エネルギーシステムを装備する。
- **人員**：24時間当直制度を実施し、封印専門家・監視員・警備員・緊急処理員を配備する。
- **緊急**：封印の損傷・闇霊魂の脱走・元宿主の霊魂の死亡などの複数の緊急計画を策定し、定期的に演習を行う。

### （六）封印の解除と転換

以下の状況では、封印を解除するか処置タイプを転換することができる：

- **元宿主の回復**：封印期間中に元宿主の霊魂が徐々に回復し、分離または融合の条件を備えた場合、封印を解除して分離配置型または共生融合型に転換することができる。
- **闇の更生**：封印期間中に闇霊魂が更生の可能性を示した場合、封印を解除して制御された条件下で更生の試みを行うことができる。
- **封印の失敗**：封印に修復不可能な損傷または弱化が発生し、闇の置換体の危険性が制御不能になった場合、消滅型処置に転換することができる。
- **元宿主の死亡**：封印期間中に元宿主の霊魂が完全に死亡した場合、闇の置換体は純粋な闇の存在となり、その危険性に応じて消滅型に転換するか封印を継続することができる。

## 第五節 第四類：消滅型処置

消滅型処置は四つの分岐の中で最も厳しい処置方法であり、救済不可能で危険性が極めて高い闇の置換体に適用され、闇霊魂を消滅させ（必要に応じて身体全体を消滅させ）、脅威を除去する。

### （一）適用条件

消滅型処置は以下の状況に適用される：

1. 闇の置換体が第五段階（完全置換期）にあり、元宿主の霊魂が完全に死亡し、身体が完全に闇霊魂に支配され、純粋な闇の存在となっている。
2. 闇の置換体が第四段階にあり、元宿主の霊魂がまだ存在するがもはや回復不可能であり、融合・分離・封印のいずれも実行不可能で、その危険性が持続的に増大している。
3. 闇の置換体のリスクレベルが第四級（極高リスク）であり、宇宙級の破壊性を有し、文明の存続を直接脅かし、他のいかなる処置方法もその脅威を制御できない。
4. 封印監視型処置において、封印が失敗し再封印できず、闇の置換体の危険性が制御不能である。
5. 双魂倫理審査委員会が消滅計画を承認している（極高リスクの緊急状況では先に処置して後に承認を補うことができる）。

### （二）消滅の原則

消滅型処置は生命の消滅に関わるため、厳格に以下の原則に従わなければならない：

- **最後の手段の原則**：消滅は他のすべての処置方法が実行不可能な場合の最後の手段でなければならない。
- **比例の原則**：消滅の強度は脅威の程度に適合しなければならず、過度な力の使用は禁止される。
- **最小苦痛の原則**：消滅はできるだけ無痛かつ迅速な方法を採用し、闇霊魂（および元宿主の霊魂がまだ存在する場合はそれ）の苦痛を減らす。
- **元宿主尊重の原則**：元宿主の霊魂がまだ存在する場合、消滅前にできるだけ元宿主の霊魂を清醒かつ尊厳ある状態に保ち、必要に応じて元宿主に友人や親族との別れを許可する。
- **完全記録の原則**：消滅の全プロセスを記録し、完全なアーカイブを形成し、審査と追跡可能性に備える。
- **事後審査の原則**：消滅完了後に事後審査を行い、消滅の必要性と適切性を評価し、経験と教訓を総括する。

### （三）消滅方法

闇の置換体の力のレベルと特徴に応じて、以下の消滅方法を選択する：

| 消滅方法 | 原理 | 適用対象 |
|----------|------|----------|
| 聖光浄化消滅 | 高強度の聖光エネルギーを使用して闇霊魂を浄化し、光の中で消滅させる | 中下レベルの力の闇の置換体 |
| 霊魂殲滅術 | 闇霊魂の霊魂核心を直接攻撃して殲滅し、完全に消滅させる | 高レベルの力の闇の置換体 |
| 空間追放消滅 | 闇の置換体を虚空または時間の果てに追放し、時空の衰退の中で消滅させる | 強力な物理的防御を持つ闇の置換体 |
| アンカー本源消滅 | アンカー本源エネルギーを召喚し、闇の置換体を分解して宇宙本源に還元する | 宇宙級の危険な闇の置換体 |
| 多次元強者連合消滅 | 複数の多次元最強者が連合し、絶対的な力で闇の置換体を抑圧し消滅させる | 極めて高いレベルの力の闇の置換体 |
| 自爆誘導消滅 | 厳格な制御のもとで闇の置換体の闇エネルギーの自爆を誘導し、エネルギー爆発の中で消滅させる | 不安定なエネルギーを持つ闇の置換体 |

### （四）処置ステップ

| ステップ | 名称 | 具体的内容 | 責任機関 |
|----------|------|------------|----------|
| 第一ステップ | 倫理審査 / 緊急承認 | 通常の状況では双魂倫理審査委員会が審査と承認を行う；極高リスクの緊急状況では現場の最高責任者が命令し、後に承認を補う | 双魂倫理審査委員会 / 現場の最高責任者 |
| 第二ステップ | 計画策定 | 消滅方法・力の配分・安全措置・緊急計画・環境影響評価を含む詳細な消滅計画を策定する | 作戦指揮部 + 技術専門家チーム |
| 第三ステップ | 力の集中 | 消滅の実施に必要な修行者・技術人員・装置・エネルギー資源を集中させる | 警備部 + 高レベル修行者 |
| 第四ステップ | 区域封鎖 | 消滅区域を封鎖し、周辺人員を退避させ、安全警戒線を設定する | 警備部 + 地方政府 |
| 第五ステップ | 抑圧制圧 | まず抑圧力で闇の置換体の行動を制御し、その脱走またはより大きな破壊を防止する | 高レベル修行者 + 警備部隊 |
| 第六ステップ | 消滅実施 | 消滅計画に従って消滅を実施し、全プロセスを監視し、異常が現れたら直ちに緊急計画を開始する | 高レベル修行者 + 技術チーム |
| 第七ステップ | 死亡確認 | 闇霊魂（および身体）が完全に消滅したことを確認し、残留エネルギーまたは霊魂の断片があるか検出する | 監視チーム + 識別専門家チーム |
| 第八ステップ | 環境修復 | 消滅区域の環境修復を行い、残留する闇エネルギーを浄化し、生態平衡を回復する | 環境部 |
| 第九ステップ | 事後処理 | 元宿主の友人や親族に通知し（元宿主が死亡した場合）、元宿主の遺産を処理し、心理カウンセリングを行う | 民事事務部 + 心理カウンセラー |
| 第十ステップ | アーカイブと事後審査 | 消滅の全プロセスの記録をアーカイブし、事後審査を行い、必要性と適切性を評価する | 生命管理局 + 倫理審査委員会 |

### （五）緊急消滅手順

文明の存続を直接脅かす第四級（極高リスク）の闇の置換体に対しては、緊急消滅手順が適用される：

1. 現場の最高レベルの責任者は直ちに緊急消滅の開始を命令することができ、事前の倫理審査は必要ないが、消滅後24時間以内に記録のために双魂倫理審査委員会に報告しなければならない。
2. 緊急消滅では文明の最高レベルの力とエネルギー資源を使用することができ、アンカーエネルギーの集中召喚と多次元最強者の連合作戦を含む。
3. 緊急消滅の優先目標は脅威を除去し、文明の生命と安全を保護することであり、消滅方法の「優雅さ」や「無痛さ」を追求しない（ただし依然としてできるだけ付随的損害を減らすべきである）。
4. 緊急消滅後には全面的な環境評価と修復を行い、残留する闇エネルギーと二次災害を防止しなければならない。
5. 緊急消滅の事例は事後的な深い検討と分析を行い、経験と教訓を総括し、早期警戒と処置のメカニズムを改善しなければならない。

## 第六節 四つの分岐処置の転換メカニズム

闇の置換体の処置は固定的ではなく、処置プロセス中の状況の変化に応じて、四つの分岐の間で転換することができる：

| 転換方向 | 転換条件 | 転換手順 |
|----------|----------|----------|
| 融合 → 分離 | 融合の試みが失敗したか、融合後に深刻な不安定が現れた | 再評価し、倫理審査の承認後に分離に転換 |
| 融合 → 封印 | 融合が失敗し分離が実行不可能で、リスクを制御する必要がある | 再評価し、倫理審査の承認後に封印に転換 |
| 融合 → 消滅 | 融合が制御不能になり、新しい霊魂が制御不能な破壊性を有する | 緊急評価し、直ちに消滅に転換 |
| 分離 → 封印 | 分離が失敗したか、分離後に元宿主が回復できず、リスクを制御する必要がある | 再評価し、倫理審査の承認後に封印に転換 |
| 分離 → 消滅 | 分離プロセス中に闇霊魂が脱走し制御不能になった | 緊急評価し、直ちに消滅に転換 |
| 封印 → 融合 | 封印期間中に元宿主の霊魂が回復し、融合の条件を備えた | 定期再評価で発見し、倫理審査の承認後に融合に転換 |
| 封印 → 分離 | 封印期間中に元宿主の霊魂が回復し、分離の条件を備えた | 定期再評価で発見し、倫理審査の承認後に分離に転換 |
| 封印 → 消滅 | 封印が失敗し再封印できず、危険性が制御不能である | 緊急評価し、直ちに消滅に転換 |
| 消滅 → その他 | 消滅は最後の手段であり、一旦実施されると不可逆である | 適用不可 |

## 結語

闇の置換体の四つの分岐処置は、アンカー共生文明の生命統治の傑作である。共生融合の積極的な救済から、分離配置の精密な切断まで、封印監視の忍耐強い待機まで、そして消滅型の最後の手段まで、四つの分岐は最も穏やかなものから最も厳しいものまでの完全な処置スペクトルを形成し、闇の置換体の様々な可能な状況をカバーしている。この処置システムは「すべての霊魂を全力で救う」という倫理的底線を保持するだけでなく、「制御不能な脅威を断固として除去する」という安全的底線も保持しており、生命倫理と安全統治の間における共生文明の精緻なバランスを反映している。
