# 跨位面探索紀元

| 項目 | 内容 |
|------|------|
| 文書番号 | 78 |
| 所属モジュール | 歴史紀元と重大事件 |
| コアキーワード | 跨位面探索、位面大発見、考古協定、先観測後干渉、星間共生 |

## 第一節 跨位面探索紀元の開啓条件

跨位面探索紀元は万族共和成立後に開啓された新紀元であり、四階段昇維経路における「意識進化」から「星間共生」への移行段階に対応する。この紀元の開啓には三つの条件が同時に成熟する必要がある:

- **技術条件**: 空間法理技術が「源空」の境地に達し、跨位面チャネルの安定的な開啓が可能になる; 複製鏡と隔離空間技術が成熟し、低汚染探索の技術的保障を提供する
- **制度条件**: 万族共和が成立し、統一された跨位面探索政策と考古協定の制定が完了する
- **動力条件**: 既知位面の昇維作業が秩序立って推進され、文明が未知位面へ拡張する能力と意欲を持つ

これら三つの条件が同時に成熟したとき、万族共和は正式に「大探索計画」の起動を宣言し、跨位面探索紀元がここに開啓される。

## 第二節 跨位面探索の基本原則

跨位面探索は以下の基本原則を厳格に遵守し、これらの原則は『跨位面探索基本法』に書き込まれている:

| 原則 | 内包 |
|------|------|
| 先観測後有限干渉 | 未知位面に対してまず受動的観測を行い、十分な理解の後に限定的な接触と干渉を行う |
| 低汚染探索 | 複製鏡+隔離空間の考古方案を採用し、知識のみを回伝し、物質と生命を持ち込み・持ち出ししない |
| 原生文明保護 | 原生文明が存在する位面に対して、その自主発展権を尊重し、共生制度を強制的に吹き込んではならない |
| 資源共有 | 探索で発見された知識と資源は全文明の共有に帰し、いかなる組織も探索成果を独占してはならない |
| 安全優先 | 探索過程における安全は常に首位に置かれ、高危険位面の探索は厳格なリスク評価を経なければならない |

## 第三節 探索の技術手段

跨位面探索は共生文明の複数のコア技術を総合的に運用している:

1. **位面スキャン技術**: 空間法理知覚モジュールに基づく遠隔位面スキャン、標的位面に接触することなくその基本情報（空間構造、エネルギーレベル、生命徴候など）を取得可能
2. **複製鏡考古方案**: 標的位面に対して高精度な鏡像複製を行い、隔離空間内で鏡像複製に対して深入りした研究を行い、知識のみを回伝
3. **跨位面通信プローブ**: 微型の法則通信装置、標的位面に送入して近距離観測を行うことができ、データは跨位面通信ネットワークを通じてリアルタイムで回伝
4. **意識域知覚**: 高階修錬者が意識域を通じて標的位面に対して遠隔知覚を行い、スキャン技術では捕捉できない意識層面の情報を取得
5. **アンカー遠隔配置**: 安全レベルの高い位面に対して、臨時アンカーを遠隔配置し、安定した接続チャネルを構築可能

## 第四節 探索の組織と実施

跨位面探索は万族共和の「跨位面探索局」によって統一的に組織・実施され、「階級探索」のモデルを採用している:

| 探索等級 | 標的類型 | 探索方式 | 人員配置 |
|----------|----------|----------|----------|
| 一級探索 | 無生命の荒廃位面 | 遠隔スキャン+複製鏡研究 | 技術チーム主体 |
| 二級探索 | 低等生命のある位面 | 複製鏡考古+限定実地考察 | 技術チーム+生物学者 |
| 三級探索 | 原生文明のある位面 | 先観測後接触、接触協定を厳格遵守 | 完全チーム+外交官+倫理観察員 |
| 四級探索 | 高危険/未知位面 | 隔離空間模擬研究のみ、実地接触禁止 | 最高級安全チーム |

各探索プロジェクトは「探索申請—リスク評価—倫理審査—批准実施—過程監視—成果共有」の完全なプロセスを経なければならない。

## 第五節 探索紀元の重大発見

跨位面探索紀元が開啓された後、共生文明は一連の重大発見を取得した:

- **新種族発見**: 未知位面においてこれまで未知の大量の知恵種族が発見され、万族譜系が大幅に拡張された。これらの新種族は自発的な選択の後、徐々に万族共和に加入した
- **新法則発見**: 異なる位面の法則構造には差異が存在し、探索中に多種の新しい法則変異体が発見され、三百套修錬体系の理論基礎が豊かになった
- **古文明遺跡**: 前アンカー時代の絶滅文明の複数の遺跡が発見され、複製鏡考古を通じて大量の貴重な歴史知識が取得された
- **异位面共生文明**: 一部の位面において独立して共生理念を発展させた原生文明が発見され、アンカー共生文明と空間を越えた思想的共鳴を形成した
- **宇宙境界探索**: 探索が徐々に衡元宙の既知の境界に触れ、宇宙全体の構造に対する認識が不断に深化している

## 第六節 探索における挑戦と反省

跨位面探索は順風満帆ではなく、過程において挑戦にも遭遇した:
- **文化衝突**: 原生文明との接触において文化的誤解と衝突が発生し、接触協定の不断の完善を促した
- **探索倫理争議**: 「原生文明に能動的に接触すべきか」について持続的な倫理弁論が存在し、最終的に「能動せず、回避せず、選択を尊重する」という共識が形成された
- **安全事故**: 高危険位面探索において隔離空間バリア破損事故が発生した; 深刻な結果は引き起こさなかったが、安全基準の更なる向上を推進した
- **資源配分**: 大規模探索には大量の資源消費が必要であり、探索投入と本土民生投入の間のバランスが政治弁論の焦点となった

## 結語

跨位面探索紀元はアンカー共生文明の「大航海時代」である。それは文明の視野を既知位面から宇宙全体に拡張し、新世界を発見すると同時に自身に対する理解も深化させた。複製鏡+隔離空間の低汚染探索方案により、共生文明の探索は歴史上の一切の略奪式植民拡張と区別される——私たちが持ち込むのは征服と略奪ではなく、尊重と知識である; 私たちが持ち帰るのは資源と奴隷ではなく、理解と智慧である。探索された位面が十分に多く、アンカーネットワークが十分に密になったとき、星間共生時代の扉がゆっくりと開かれるだろう。
