# 共生労働法

| プロジェクト | 内容 |

| 所属モジュール | 法律体系と統治枠組み |

## 第一節 立法目的と基本原則

《共生労働法》はアンカー共生文明の法律体系において《共生憲法》と並ぶ核心的法律の一つであり、衡元宙内のすべての労働と貢献行為を規範化し、「多労多得、自生自長」の分配秩序を確立し、法律のレベルから略奪式搾取の土壌を根絶することを目的とする。

本法は以下の基本原則を確立する：

| 原則 | 内包 |
|------|------|
| 労働尊厳原則 | すべての合法的労働は法律によって保護され、労働者の人格尊厳は侵害されない |
| 多労多得原則 | 労働報酬は貢献量と直接的に連動し、貢献が大きいほど収益が高く、労なくして得ることは禁止される |
| 自発労働原則 | 強制労働と奴隷制を禁止し、労働者は労働内容と労働方式を自由に選択する権利を有する |
| 公平報酬原則 | 同一労働同一報酬、種族、修為、出身に基づく報酬差別を禁止する |
| 労働保障原則 | 国家と文明は労働者に安全な労働環境と基本的社会保障を提供する義務を有する |
| 共生協作原則 | 労働者間の協力と互助を奨励し、悪性競争とゼロサムゲームに反対する |

## 第二節 労働者の基本権利

共生労働法は衡元宙内のすべての労働能力を有する生命に以下の権利を付与する：

1. **平等就業権**：いかなる生命も求職と就業の過程で種族、修為、出身、性別などの要因による差別を受けない。
2. **自由選業権**：労働者は自身の意思と能力に基づいて職業、職場と就業場所を選択する権利を有し、法律に基づいて職業を変更する権利を有する。
3. **合理報酬権**：労働者は自身の労働貢献に見合う報酬を受ける権利を有し、報酬は文明が定める最低保障基準を下回ってはならない。
4. **休息休暇権**：労働者は合理的な労働時間の手配と定期的な休暇を受ける権利を有し、無制限に労働時間を延長することは禁止される。
5. **労働安全権**：労働者は安全で衛生的な環境で労働する権利を有し、雇用者は基準に適合する労働保護条件を提供しなければならない。
6. **職業訓練権**：労働者は職業技能訓練と修練指導を受ける権利を有し、雇用者と国家は訓練資源を提供する義務を有する。
7. **結社と協商権**：労働者は法律に基づいて労働者協会を組織または加入する権利を有し、集団協商を通じて自身の権益を維持する権利を有する。
8. **申訴救済権**：労働者は労働権益が侵害された場合、労働仲裁機構と共生法院に申訴と訴訟を提起する権利を有する。

## 第三節 聯産承包机制の法律化

聯産承包机制はアンカー共生文明の資源分配の核心制度であり、《共生労働法》はこれを法律形式で固定する：

- **承包主体**：いかなる労働能力を有する生命も承包主体となることができ、個人または集団のいずれも承包できる。
- **承包内容**：修練資源開発、位面維持、知識伝承、技術研究開発、公共サービスなどの分野を含むがこれらに限定されない。
- **承包期限**：承包内容の性質に応じて決定され、短期承包は1～3年、長期承包は5～20年、期限満了後は更新できる。
- **収益分配**：承包者の収益はその生産高と直接的に連動し、生産高の一部は公共積立に上納され、残りの部分は承包者の所有となる。
- **退出机制**：承包者は合理的な期限内に事前通知した後に承包から退出する権利を有し、承包関係に強制的に縛り付けられることはない。
- **紛争解決**：承包紛争は優先的に労働仲裁を通じて解決され、仲裁結果に不服がある場合は共生法院に提訴できる。

## 第四節 特殊労働保護

衡元宙内の異なる生命形態の特殊な需要に対応するため、本法は特殊労働保護制度を設立する：

| 保護対象 | 特殊保護措置 |
|----------|--------------|
| 初級修練者 | その能力範囲を超える高リスク労働を手配してはならず、導師の指導を配备しなければならない |
| 妊産婦女性生命 | 6ヶ月以上の有給産休を享有し、授乳期間中は高強度労働を手配してはならない |
| 障害と傷病生命 | 合理的な労働職場調整とバリアフリー労働環境保障を享有する |
| 異族労働者 | 雇用者は異族の生理的特徴と文化的習慣を尊重し、適応的な労働条件を提供しなければならない |
| 高齢労働者 | 一定の年齢に達した後、労働強度の軽減または顧問的職場への転換を申請できる |

## 第五節 法律責任と実施保障

雇用者が本法の規定に違反した場合、情状の軽重に応じて以下の責任を負う：

1. 労働者の应得報酬及び賠償金を支払う（賠償金は未払い報酬の1～3倍）。
2. 期限付き是正を命じられ、期限内に是正しない場合は罰金が科される。
3. 情状が深刻な場合、経営許可を取り消し、関連責任者を一定期間管理業務に従事することを禁止する。
4. 犯罪を構成する場合は、法律に基づいて刑事責任を追及する。

国家は労働監察機構を設立し、雇用者が労働法を遵守する状況を監督検査する責任を負う。労働者協会は労働者を代表して労働監察と集団協商に参与する権利を有する。

## 結語

《共生労働法》はアンカー共生文明の「多労多得」理念の法律的担体である。それは労働を搾取の対象から尊重される権利に転化し、分配を略奪式占有から貢献式報酬に転化し、万族共進のために堅実な労働制度の基礎を築いた。
