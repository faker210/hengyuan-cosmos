# 教育保障法

## 第一節 立法目的と基本原則

《教育保障法》はアンカー共生文明の五部の付帯法の一つであり、衡元宙内のすべての生命の受教育権を保障し、「共生進化」を核心理念とする教育体系を構築し、万族共進のために知識と人材の支えを提供することを目的とする。

本法は以下の基本原則を確立する：

| 原則 | 内包 |
|------|------|
| 教育公平原則 | すべての生命は種族、修為、出身を問わず、平等な受教育機会を享有する |
| 因材施教原則 | 各生命の天賦の差異と進化経路の選択を尊重し、個性化された教育方案を提供する |
| 知行合一原則 | 理論知識と実践修練を結合し、実際から遊離した空論教育に反対する |
| 開放共享原則 | 教育資源は全社会に開放され、三百套本源修練体系の基礎法門は無料で伝授される |
| 生涯学習原則 | 教育は生命の全過程を貫き、各段階の継続的な学習と能力向上を支援する |
| 文化多元原則 | 各族の文化伝統を尊重し、多元文化交流と相互鑑賞を奨励する |

## 第二節 受教育権の法律保障

本法は、受教育権は共生憲法が各生命に付与した基本権利であり、国家と文明はこの権利の実現を保障する義務を有することを明確に規定する：

1. **無料基础教育**: すべての生命は無料の基础教育を受ける権利を有し、通用知識、基礎修練法門、共生文明理念などの内容を含み、学制は6～12年で、種族の発育周期に応じて調整される。
2. **無料修練入門**: 三百套宇宙本源修練体系の基礎法門はすべての生命に無料で開放され、いかなる組織と個人も基礎修練法門を私有して有料で伝授することはできない。
3. **進学機会平等**: 各級各類教育機構は募集において種族、修為、出身などの差別的条件を設定してはならず、合格基準は公開透明である。
4. **特殊教育保障**: 障害生命、異族生命、偏遠位面生命などの群体に適応した特殊教育資源と遠隔教育支援を提供する。
5. **教育救助制度**: 経済困難な学習者に助学金、奨学金と無利子融資を提供し、経済的理由で受教育機会を失わないことを確保する。

## 第三節 教育体系架构

アンカー共生文明の教育体系は四つの層級に分かれ、各層級の間は有機的に接続している：

| 層級 | 名称 | 目標 | 学制 |
|------|------|------|------|
| 第一層級 | 啓蒙教育 | 基本認知能力と共生意識を養成し、基礎修練法門を伝授する | 3-6年 |
| 第二層級 | 基础教育 | 通用知識と修練理論を系統的に学習し、個体の天賦方向を発見する | 6-9年 |
| 第三層級 | 専門教育 | 選定された修練体系または専門分野について深入した学習と実践を行う | 3-10年 |
| 第四層級 | 高階研修 | 高階修練者と研究者向けの前沿探索と革新研修 | 無制限 |

さらに、「導師ネットワーク制度」を設立する：一定の修為に達した修練者は能力の範囲内で初級修練者を指導する義務を有し、指導の貢献は聯産承包机制の貢献量に計上され、相応の資源配分を享有する。

## 第四節 教育機構と教師

- **公立教育機構**: 国家または文明共同体によって設立され、無料の基础教育と公共教育サービスを担い、経費は公共積立によって保障される。
- **私立教育機構**: 社会力量によって法律に基づいて設立され、合理的な費用を徴収することができるが、教育主管部門の監督を受けなければならず、虚偽宣伝と略奪式料金徴収を行ってはならない。
- **修練宗門**: 伝統的な修練組織は登録後に専門教育機構として活動を展開することができ、教育法の規定を遵守しなければならず、修練資源を閉鎖的に独占してはならない。
- **教師の権利と義務**: 教師は学術自由、合理的報酬、職業訓練などの権利を享有すると同時に、教育育人、模範となること、学生のプライバシーを守ることなどの義務を負う。

## 第五節 教育内容と課程標準

教育内容は以下の要求に適合しなければならない：

1. 共生文明の核心理念と反略奪主義教育を含み、学習者の共生意識を養成する。
2. 三百套本源修練体系の基礎理論と入門法門を含む。
3. 宇宙法則、位面知識、生命科学などの通用科学知識を含む。
4. 万族の歴史と文化を含み、各族の相互理解と尊重を促進する。
5. 実践修練と社会サービスの環節を含み、知行合一の能力を養成する。
6. 略奪式修練理念と差別的思想の伝播を禁止する。

## 第六節 法律責任

本法の規定に違反する行為は、情状の軽重に応じて以下の責任を負う：

- 適齢生命が義務教育を受けることを拒否または妨害した場合、是正を命じ、処罰する。
- 教育機構が違反して料金を徴収し、虚偽宣伝をした場合、料金の返還を命じ、罰金を科し、情状が深刻な場合は办学許可を取り消す。
- 教師が体罰または学生を差別した場合、処分を与え、情状が深刻な場合は教師資格を取り消し、法律責任を追及する。
- 公共修練資源を私有し、独占して料金を徴収した場合、違法所得を没収し、罰金を科す。

## 結語

《教育保障法》はアンカー共生文明の「人人有路」理念の教育実践である。それは受教育権を保障し、層級化された教育体系を構築し、修練資源を開放することにより、各生命が自身に適した進化経路を獲得できることを確保し、万族共進のために絶え間なく知識と人材を送り出す。
