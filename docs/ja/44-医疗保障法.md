# 医療保障法

| プロジェクト | 内容 |
|--------------|------|
| 文書番号 | 44 |
| 所属モジュール | 法律体系と統治枠組み |
| コアキーワード | 医療権、共生医療、修練損傷治療、生命健康、医療保険体系 |

## 第一節 立法目的と基本原則

《医療保障法》はアンカー共生文明の五部の付帯法の一つであり、衡元宙内のすべての生命の健康権と医療権を保障し、万族をカバーする共生医療体系を構築し、各生命が病気や怪我の際にタイムリーで効果的な治療を受けられることを確保することを目的とする。

本法は以下の基本原則を確立する：

| 原則 | 内包 |
|------|------|
| 健康優先原則 | 生命健康はすべての進化の基礎であり、国家と文明は生命健康の保障を優先的な地位に置く |
| 普遍カバー原則 | 医療保障はすべての生命をカバーし、種族、修為、出身、経済状況を問わない |
| 階層診療原則 | 基層医療、区域医療、高階医療の三級診療体系を構築し、医療資源を合理的に配分する |
| 防治結合原則 | 予防を主とし、予防と治療を結合し、修練損傷の予防とリハビリテーションを重視する |
| 異族適応原則 | 異なる種族の生理的特性に応じて適応した医療方案を提供し、人族基準で一律に処理することを禁止する |
| 公益属性原則 | 基本医療サービスは公益属性を有し、営利目的で生命の治療権を剥奪してはならない |

## 第二節 生命健康権の法律保障

本法は、生命健康権は共生憲法が各生命に付与した基本権利であり、具体的に以下を含むことを明確に規定する：

1. **基本医療権**: 各生命は無料の基本医療サービスを受ける権利を有し、一般疾患の診断治療、基本薬物、定期健康診断などを含む。
2. **救急救治権**: 各生命は突発的な病気や怪我の際に緊急治療を受ける権利を有し、医療機関はいかなる理由でも救急治療を拒否してはならない。
3. **修練損傷救治権**: 修練者が修練過程で受けたエネルギー紊乱、経絡損傷、走火入魔などの損傷について、専門的な治療を受ける権利を有する。
4. **知情同意権**: 患者は自身の病状、治療方案、リスクと予後を知る権利を有し、治療方案を選択または拒否する権利を有する。
5. **プライバシー保護権**: 患者の医療情報と身体データは法律で保護され、患者の同意なしに漏洩または他の目的に使用してはならない。
6. **リハビリ保障権**: 病気や怪我の患者はリハビリ治療と補助器具を受ける権利を有し、労働と生活能力の回復を支援する。

## 第三節 共生医療体系架构

アンカー共生文明の医療体系は三級に分かれ、各級の間に紹介と協力の仕組みが構築されている：

| 級 | 名称 | 職能 | カバー範囲 |
|----|------|------|------------|
| 第一級 | 基層医療ステーション | 一般疾患の診断治療、予防保健、基本健康診断、救急搬送 | コミュニティ/村落/小型位面 |
| 第二級 | 区域医療センター | 専門診療、手術治療、修練損傷の初期処理、リハビリ | 都市/区域/中型位面 |
| 第三級 | 高階医療総院 | 難治重症、高階修練損傷、意識域疾患、跨種族難病 | 文明核心/大型位面 |

さらに、「修練損傷専門科」を設立する：修練過程における各種損傷を専門的に処理し、エネルギー過負荷、経絡断裂、心魔侵入、霊魂創傷などを含み、修練法則に精通した医療人員を配置する。

## 第四節 医療保障基金

医療保障基金は共生医療体系運営の経済基礎であり、その出所は以下を含む：

- 公共積立金の交付（主な出所）
- 聯産承包机制における医療保障の積立
- 社会寄付
- 基金投資収益

基金の支払範囲は以下を含む：基本医療サービス費用、救急費用、修練損傷治療費用、基本薬物費用、リハビリ費用など。患者個人はわずかな自己負担費用のみを支払い、経済困難者には減免を実施する。

## 第五節 医療機関と医療人員

- **公立医療機関**: 国家または文明共同体によって設立され、基本医療サービスと公衆衛生職能を担い、経費は医療保障基金によって保障される。
- **私立医療機関**: 社会力量によって法律に基づいて設立され、高端医療サービスを提供できるが、医療主管部門の監督を受けなければならず、救急患者を拒否してはならない。
- **異族医療機関**: 特殊種族の生理的ニーズに対応して設立された専門医療機関で、異族医療人員を配置する。
- **医療人員の権利と義務**: 医療人員は執業保護、合理的報酬、職業訓練などの権利を享有すると同時に、救命救急、患者尊重、医療秘密保持などの義務を負う。

## 第六節 公衆衛生と予防

国家は公衆衛生体系を構築し、以下の職能を履行する：

1. 伝染病の監視と予防制御、跨位面疫情警報机制を構築する。
2. 全民健康診断と健康記録管理。
3. 修練安全宣伝と修練損傷予防指導。
4. 環境衛生と食品医薬品安全監督。
5. 突発公衆衛生事件の緊急応答。

## 第七節 法律責任

本法の規定に違反する行為は、情状の軽重に応じて以下の責任を負う：

- 医療機関が救急患者を拒否した場合、是正を命じ罰金を科し、深刻な結果を引き起こした場合は執業許可を取り消す。
- 医療人員が重大な過失により患者に損害を与えた場合、賠償責任を負い、情状が深刻な場合は執業資格を取り消す。
- 医療機関が違反して料金を徴収し、過剰医療を行った場合、料金の返還を命じ罰金を科す。
- 患者の医療プライバシーを漏洩した場合、精神的損害賠償を負い、情状が深刻な場合は刑事責任を追及する。
- 偽薬、劣悪薬を生産販売した場合、違法所得を没収し罰金を科し、犯罪を構成する場合は刑事責任を追及する。

## 結語

《医療保障法》はアンカー共生文明の「人人有路」理念の健康分野における体現である。それは普遍的にカバーされた医療保障体系を構築し、修練損傷専門科を設立し、救急救治権を保障することにより、各生命が病気や怪我の際にタイムリーな治療を受けられることを確保し、万族共進のために健康の基礎を固める。
