# 住宅保障法

| プロジェクト | 内容 |
|--------------|------|

| 所属モジュール | 法律体系と統治枠組み |

## 第一節 立法目的と基本原則

《住宅保障法》はアンカー共生文明の五部の付帯法の一つであり、衡元宙内のすべての生命の居住権を保障し、公平で持続可能な住宅保障体系を構築し、空間法的管轄技術を利用して万族に適した居住空間を提供し、住宅分野における投機と略奪を防止することを目的とする。

本法は以下の基本原則を確立する：

| 原則 | 内包 |
|------|------|
| 居住保障原則 | 各生命は適した居住空間を得る権利を有し、国家と文明は基本的な居住ニーズを保障する義務を有する |
| 公益優先原則 | 住宅はまず生活必需品であり投機商品ではなく、保障住宅は公益属性を有する |
| 空間効率原則 | 空間法的管轄技術を利用して空間利用効率を高め、宜居空間を拡張する |
| 異族適応原則 | 異なる種族の生理的特性と生活習慣に応じて適応した居住空間を提供する |
| 宜居環境原則 | 居住空間は良好な生態環境、インフラストラクチャ、公共サービスを備えるべきである |
| 反投機原則 | 住宅を対象とした投機炒作を禁止し、住宅が富を略奪するツールとなることを防止する |

## 第二節 居住権の法律保障

本法は、居住権は共生憲法が各生命に付与した基本権利であり、具体的に以下を含むことを明確に規定する：

1. **基本居住権**: 各生命は最低基準を下回らない居住空間を得る権利を有し、最低基準は種族の体型と生活ニーズに応じて決定される。
2. **保障住宅申請権**: 条件を満たす生命は保障住宅を申請する権利を有し、申請条件と配分基準は公開透明である。
3. **居住安全権**: 居住空間は安全基準を満たさなければならず、危険住宅と居住に適さない空間は賃貸または配分してはならない。
4. **居住安定権**: 保障住宅の居住者は条件を満たす場合に安定した居住権を享有し、恣意的に退去させてはならない。
5. **居住環境権**: 居住者は清潔な空気、水源と良好な周辺環境を得る権利を有し、環境汚染に対して苦情を申し立てる権利を有する。
6. **住宅改造権**: 居住者は建築の安全と他人の権益に影響を与えない前提で、居住空間に合理的な改造を行う権利を有する。

## 第三節 住宅保障体系

アンカー共生文明の住宅保障体系は三種類の住宅に分かれ、異なるニーズの層をカバーする：

| 種類 | 名称 | 保障対象 | 配分方式 | 賃料/価格 |
|------|------|----------|----------|-----------|
| 第一種 | 公共賃貸住宅 | 低所得層、初級修練者、新移民 | 申請審査制、順番待ち配分 | 象徴的な低賃料 |
| 第二種 | 共有持分住宅 | 中所得層、中級修練者 | 申請審査制、抽選配分 | 市場価格より低く、個人と国家の共有持分 |
| 第三種 | 商品住宅 | 高所得層、高階修練者 | 市場取引 | 市場価格、規制の制約を受ける |

さらに、空間折りたたみ技術を利用して「空間折りたたみ居住区」を建設する：限られた物理的空間内で空間折りたたみ技術により居住面積を拡張し、高密度地域により多くの居住空間を提供する。空間折りたたみ居住区は安全評価を経なければならず、空間の安定性を確保する。

## 第四節 異族住宅適応

衡元宙内の異なる種族の特殊な居住ニーズに対応するため、本法は異族住宅適応制度を設立する：

- **水生種族**: 水中居住空間または水陸両用住宅を提供し、水循環と水質維持システムを備える。
- **飛行種族**: 高高度居住空間または離発着プラットフォーム付き住宅を提供し、航空交通管理を備える。
- **エネルギー生命**: エネルギー濃度が適した居住空間を提供し、エネルギー安定装置を備える。
- **巨大種族**: 大規模な居住空間を提供し、建築構造は特別に補強される。
- **微型種族**: 微型居住区を提供し、スケーリングチャネルと専用施設を備える。

異族住宅適応基準は住宅主管部門が各族代表と共同で制定し、定期的に更新する。

## 第五節 住宅建設と管理

- **住宅建設計画**: 国家は人口増加と移民状況に応じて住宅建設計画を制定し、住宅の供給と需要のバランスを確保する。
- **建設基準**: 保障住宅の建設は安全、環境、宜居の基準を満たさなければならず、建設の質を低下させることを禁止する。
- **財産管理**: 居住区は自治管理と専門的な財産管理を組み合わせたモデルを実施し、居住者は財産管理の決定に参加する権利を有する。
- **住宅修繕**: 保障住宅の修繕は住宅管理機構が責任を負い、修繕資金は公共積立から支出される。
- **退出机制**: 保障住宅の居住者の収入または修練レベルが保障基準を超えた場合、保障住宅を退出するか商品住宅に転換すべきであり、退出には合理的な移行期間が与えられる。

## 第六節 反投機と監督

住宅分野における投機と略奪を防止するため、本法は以下の監督措置を設立する：

1. 個人が保有する商品住宅の数を制限し、限度額を超えた部分には累進的な住宅税を徴収する。
2. 保障住宅の転貸と転売を禁止し、違反者は保障資格を取り消され住宅を回収される。
3. 住宅取引情報公開制度を構築し、暗箱操作と価格操作を防止する。
4. 不動産開発業者に対して資質管理と資金監督を実施し、未完成と詐欺を防止する。
5. 住宅苦情と紛争解決机制を設立し、居住者の合法的な権益を保障する。

## 第七節 法律責任

本法の規定に違反する行為は、情状の軽重に応じて以下の責任を負う：

- 違反して保障住宅を配分した場合、是正を命じ責任者に処分を与える。
- 保障住宅を転貸、転売した場合、保障資格を取り消し、住宅を回収し罰金を科す。
- 開発業者が建設の質を低下させた場合、やり直しを命じ罰金を科し、情状が深刻な場合は資質を取り消す。
- 住宅投機炒作を行った場合、高額な投機税を徴収し罰金を科す。
- 危険住宅を賃貸して居住者に損害を与えた場合、賠償責任を負い、情状が深刻な場合は刑事責任を追及する。

## 結語

《住宅保障法》はアンカー共生文明の「人人有路」理念の居住分野における実施である。それは分類された住宅保障体系を構築し、空間法的管轄技術を利用して居住空間を拡張し、異族の居住ニーズに適応し、住宅投機を取り締まることにより、各生命が安全で適した安定した家を持てることを確保し、万族共進のために安居保障を提供する。
