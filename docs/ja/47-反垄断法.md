# 独占禁止法

| プロジェクト | 内容 |

| 所属モジュール | 法律体系と統治枠組み |

## 第一節 立法目的と基本原則

《独占禁止法》はアンカー共生文明の五部の付帯法の一つであり、独占行為を予防し制止し、市場の公平な競争を保護し、経済運営効率を高め、消費者利益と社会公共利益を維持し、共生経済の健全な発展を促進することを目的とする。アンカー共生文明において、独占禁止は伝統的な経済分野の独占に対するだけでなく、修練資源独占、知識独占と位面独占などの特殊形態にも対象とする。

本法は以下の基本原則を確立する：

| 原則 | 内包 |
|------|------|
| 公平競争原則 | 公平な競争の市場秩序を維持し、競争を排除・制限する独占行為を禁止する |
| 反略奪原則 | 独占禁止の核心は反略奪であり、独占者が独占的地位を通じて衆生の利益を略奪することを防止する |
| 資源開放原則 | 公共修練資源と基礎知識は全社会に開放されなければならず、私人独占を禁止する |
| 効率と公平のバランス原則 | 独占禁止は競争効率を保護すると同時に、過度な分散による資源浪費も防止しなければならない |
| 跨位面適用原則 | 独占禁止法は衡元宙内のすべての位面と市場に適用され、跨位面独占も同様に規制される |

## 第二節 独占行為の類型

本法が規制する独占行為には以下の四類型が含まれる：

### （一）独占協定

独占協定とは、競争を排除・制限する協定、決定またはその他の共同行為を指し、以下を含む：

1. **水平独占協定**: 競争関係にある経営者間で締結された価格固定、生産制限、市場分割、共同取引ボイコットなどの協定。
2. **垂直独占協定**: 経営者と取引相手間で締結された再販売価格固定、最低再販売価格制限などの協定。
3. **修練資源独占協定**: 修練宗門間で締結された修練資源区域の分割、資源価格の統一、資源供給の制限などの協定。
4. **知識独占協定**: 教育機関と修練宗門間で締結された修練法門の封鎖、知識伝播の制限、学費基準の統一などの協定。

### （二）市場支配的地位の濫用

市場支配的地位とは、経営者が関連市場内で商品の価格、数量またはその他の取引条件を制御できる、あるいは他の経営者が関連市場に参入することを阻碍・影響できる市場地位を指す。市場支配的地位の濫用行為には以下が含まれる：

| 行為類型 | 具体的表現 |
|----------|------------|
| 不公正価格設定 | 不公正な高値で商品を販売するか、不公正な安値で商品を購入する |
| 略奪的価格設定 | 正当な理由なく、原価を下回る価格で商品を販売し、競争相手を排除する |
| 取引拒絶 | 正当な理由なく、取引相手との取引を拒絶する |
| 取引限定 | 正当な理由なく、取引相手が自社とのみ取引するよう限定する |
| 抱き合わせ販売 | 正当な理由なく商品を抱き合わせ販売するか、取引時にその他の不条理な条件を付加する |
| 差別的取扱い | 正当な理由なく、条件が同一の取引相手に対して取引価格などの条件で差別的取扱いをする |
| 修練資源封鎖 | 修練資源の独占的地位を利用し、競争相手または消費者に必要な資源の提供を拒絶する |
| 知識封鎖 | 知識の独占的地位を利用し、基礎修練法門を封鎖し、学習者に高額な費用の支払いを強制する |

### （三）経営者集中

経営者集中とは以下の状況を指す：経営者の合併；経営者が株式または資産の取得を通じて他の経営者に対する支配権を取得する；経営者が契約などを通じて他の経営者に対する支配権を取得するか、他の経営者に決定的な影響を与えることができる。

届出基準に達した経営者集中は、事前に独占禁止執法機関に届け出なければならず、届出のないものは集中を実施してはならない。独占禁止執法機関が経営者集中を審査する際には、以下の要素を考慮しなければならない：

1. 集中に参与する経営者の関連市場における市場シェアと市場に対する支配力。
2. 関連市場の市場集中度。
3. 経営者集中が市場参入と技術進歩に与える影響。
4. 経営者集中が消費者とその他の関連経営者に与える影響。
5. 経営者集中が修練資源開放と知識伝播に与える影響。
6. 経営者集中が国民経済発展と万族共進に与える影響。

### （四）行政権力の濫用による競争の排除・制限

行政機関および法律・法規の授権を受けて公共事務管理職能を有する組織は、行政権力を濫用して以下の行為を実施してはならない：

1. 単位または個人が指定した経営者の提供する商品を経営・購入・使用するよう限定または変相限定する。
2. 地域間、位面間の商品の自由な流通を妨げる。
3. 外地経営者、外位面経営者が本地の入札・競争入札活動に参加することを排除または制限する。
4. 外地経営者、外位面経営者が本地に投資または支店を設立することを排除または制限する。
5. 経営者に本法の規定する独占行為に従事することを強制する。
6. 競争を排除・制限する内容を含む規定を制定する。

## 第三節 修練分野の特殊独占禁止規則

修練分野はアンカー共生文明の独占禁止の重点分野であり、本法は特殊規則を設ける：

1. **基礎法門開放義務**: 三百套本源修練体系の基礎法門は公共知識に属し、いかなる組織と個人も独占・封鎖または有料伝授してはならない。
2. **修練資源公平分配**: 公共修練資源は聯産承包机制を通じて公平に分配され、宗門または個人が良質な修練資源を独占することを禁止する。
3. **修練差別禁止**: 修練宗門は招生と伝授において種族、出身、修為などに基づいて差別的条件を設定してはならない。
4. **高階知識共有義務**: 位面至高強者基準に達した修練者は、合理的な知的財産権を保護する前提で、社会に修練心得と研究成果を共有する義務を有する。
5. **位面開発独占禁止**: 新位面の開発権は公開競争方式を通じて分配され、少数勢力が位面開発権を独占することを禁止する。

## 第四節 独占禁止執法機関

国家は独占禁止執法機関を設立し、独占禁止執法活動を担当し、以下の職責を履行する：

1. 競争政策に関する研究・起草。
2. 市場全体の競争状況の調査・評価を組織し、評価報告を発布する。
3. 独占禁止ガイドラインの制定・発布。
4. 独占禁止行政执法活動の調整。
5. 独占協定、市場支配的地位の濫用、違法な経営者集中の実施などの案件の査察・処罰。
6. 行政権力の濫用による競争の排除・制限行為の査察・処罰。

独占禁止執法機関は法に基づいて独立して職権を行使し、行政機関、社会団体と個人の干渉を受けない。

## 第五節 法律責任

本法の規定に違反する行為は、情状の軽重に応じて以下の責任を負う：

- 独占協定を締結し実施した場合、違法行為の停止を命じ、違法所得を没収し、前年度の売上高の1パーセント以上10パーセント以下の罰金を科す。
- 市場支配的地位を濫用した場合、違法行為の停止を命じ、違法所得を没収し、前年度の売上高の1パーセント以上10パーセント以下の罰金を科す。
- 違法に経営者集中を実施した場合、集中の実施停止を命じ、期限付きで株式または資産を処分し、期限付きで営業を譲渡し、50万元以下の罰金を科す。
- 行政権力を濫用して競争を排除・制限した場合、上級機関が是正を命じ、直接責任者とその他の直接責任者に法に基づき処分を与える。
- 独占行為が他人に損害を与えた場合、法に基づき民事賠償責任を負う。
- 情状が深刻で犯罪を構成する場合、法に基づき刑事責任を追及する。

## 結語

《独占禁止法》はアンカー共生文明の反略奪主義の経済・修練分野における法律武器である。それは独占協定、市場支配的地位の濫用、経営者集中と行政独占を規制し、特に修練資源独占と知識独占に対して特殊規則を設けることにより、市場競争と修練資源の公平な開放を確保し、独占が衆生を略奪する新たな形態となることを防止し、万族共進のために公平な競争の制度環境を維持する。
