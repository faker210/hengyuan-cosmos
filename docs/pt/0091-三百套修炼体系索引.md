## 1. Explicação do Índice

Este índice reúne todos os trezentos conjuntos de sistema de cultivo de origem cósmica abertos pela Civilização de Simbiose de Âncora, organizados em seis categorias, cinquenta conjuntos por categoria, numerados continuamente de 001 a 300. Os três primeiros conjuntos de sistema (Dedução Iterativa, Ciclo de Vida, Controle de Lei Espacial) são as "Três Bases de Origem", que são a base de cultivo de todos os sistemas. Cada conjunto de sistema lista o número, o nome e um breve resumo da direção central. Este índice é uma ferramenta de consulta; para os métodos detalhados de cultivo e a divisão de reinos de cada sistema, consulte o documento especial do sistema correspondente.

## Conclusão

O índice completo dos trezentos conjuntos de sistema de cultivo de origem é a manifestação concreta do compromisso "todos têm um caminho" da Civilização de Simbiose de Âncora. Os sistemas das seis categorias cobrem todas as dimensões da evolução, do cultivo individual à colaboração grupal, da dedução teórica à aplicação de engenharia, garantindo que cada vida possa encontrar um caminho de cultivo adequado às suas próprias características. Este índice será atualizado dinamicamente com a otimização contínua e a adição de novos sistemas, servindo sempre como referência autoritativa para os cultivadores escolherem sistemas.
