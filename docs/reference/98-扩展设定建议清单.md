## 一、说明

本文档列出锚点共生文明设定体系中可供扩展创作的方向与建议，旨在为设定创作者提供灵感与指引，帮助其在已有框架内进行有价值的设定扩展。本清单按照模块分类，每个扩展方向包含方向描述、扩展价值、与已有设定的关联以及创作建议。需要强调的是，本清单仅为建议性参考，创作者可以在遵循设定一致性的前提下自由发挥，也可以开发本清单未涵盖的全新方向。所有扩展设定须通过文档97《设定矛盾自查表》的检查后方可正式纳入。

## 十、扩展设定的创作原则

在进行扩展设定创作时，应遵循以下原则：

1. **一致性优先**：所有扩展设定必须与已有设定保持逻辑一致，通过设定矛盾自查表的检查。
2. **现实为基**：扩展设定应基于客观规律进行合理推演，避免纯粹的空想与设定崩坏。
3. **共生立场**：扩展设定应始终坚持反掠夺、倡共生的核心立场，不得为掠夺式行为辩护。
4. **开放性**：扩展设定应保持一定的开放性，为后续的进一步扩展预留空间。
5. **实用性**：扩展设定应具有实际的创作价值，能够为故事创作、游戏设计、理论探讨提供有用的素材。

## 结语

扩展设定建议清单是锚点共生文明设定体系的"开放之门"。它表明这个设定体系不是一个封闭的、完成态的产品，而是一个持续生长、不断丰富的活的体系。三十六个扩展方向只是起点，真正的设定创造力来源于每一位参与者的想象力与热情。只要遵循设定一致性的基本原则，每一个有价值的扩展都将成为锚点共生文明宏大叙事中不可或缺的组成部分。
