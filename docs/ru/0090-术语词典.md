## I. Пояснения к Терминологии

Настоящий словарь включает центральные термины системы вселенной Симбиотической Цивилизации Якоря, направлен на унификацию использования терминов во всех документах и обеспечение согласованности и точности выражения понятий. Все термины отсортированы по первой букве их китайского пиньиня ; каждая статья содержит название термина, английское справочное название (при наличии), определение и краткое пояснение. Настоящий словарь является динамически обновляемым документом ; по мере расширения системы вселенной в него будут непрерывно добавляться новые термины.

## III. Нормы Использования Терминологии

1. Термины, включённые в настоящий словарь, являются стандартными ; все документы должны отдавать приоритет стандартным формулировкам из настоящего словаря.
2. Одно и то же понятие должно использовать один и тот же термин в разных документах ; произвольная замена синонимами не допускается.
3. Новые термины, появившиеся в новых вселенных, должны своевременно представляться в Комитет по Терминологии для рассмотрения и добавляться в словарь после одобрения.
4. При пересмотре определения термина действует последняя версия настоящего словаря, а содержание пересмотра должно быть зафиксировано в примечаниях к версии документа.
5. При цитировании термина при первом появлении может использоваться полное название, в дальнейшем — сокращение, но ясность значения в контексте должна обеспечиваться.

## Заключение

Словарь терминов — языковой краеугольный камень всей системы вселенной. Единая терминологическая система обеспечивает концептуальную согласованность между сотней документов, позволяя читателям без труда переключаться между разными модулями без неоднозначности понимания. По мере обогащения и совершенствования системы вселенной настоящий словарь будет непрерывно обновляться, всегда оставаясь авторитетным источником терминологии для всех документов.
