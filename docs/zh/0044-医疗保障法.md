# 医疗保障法

| 项目 | 内容 |

## 一、立法目的与基本原则

《医疗保障法》是锚点共生文明五部配套法之一，旨在保障衡元宙内一切生命的健康权与医疗权，建立覆盖万族的共生医疗体系，确保每个生命在伤病时都能获得及时、有效的救治。

本法确立以下基本原则：

| 原则 | 内涵 |
|------|------|
| 健康优先原则 | 生命健康是一切进化的基础，国家与文明将保障生命健康置于优先地位 |
| 普遍覆盖原则 | 医疗保障覆盖一切生命，不分种族、修为、出身与经济状况 |
| 分级诊疗原则 | 建立基层医疗、区域医疗、高阶医疗三级诊疗体系，合理分配医疗资源 |
| 防治结合原则 | 预防为主、防治结合，重视修炼损伤的预防与康复 |
| 异族适配原则 | 针对不同种族的生理特性提供适配的医疗方案，禁止以人族标准一刀切 |
| 公益属性原则 | 基本医疗服务具有公益属性，不得以盈利为目的剥夺生命的救治权 |

## 二、生命健康权的法律保障

本法明确规定，生命健康权是共生宪法赋予每个生命的基本权利，具体包括：

1. **基本医疗权**：每个生命有权获得免费的基本医疗服务，包括常见病诊治、基础药物、常规体检等。
2. **急救救治权**：每个生命在突发伤病时有权获得紧急救治，医疗机构不得以任何理由拒绝急救。
3. **修炼损伤救治权**：修炼者在修炼过程中遭受的能量紊乱、经脉损伤、走火入魔等损伤，有权获得专业救治。
4. **知情同意权**：患者有权了解自身病情、治疗方案、风险与预后，有权选择或拒绝治疗方案。
5. **隐私保护权**：患者的医疗信息与身体数据受法律保护，未经患者同意不得泄露或用于其他目的。
6. **康复保障权**：伤病患者有权获得康复治疗与辅助器具，帮助其恢复劳动与生活能力。

## 三、共生医疗体系架构

锚点共生文明的医疗体系分为三级，各层级之间建立转诊与协作机制：

| 层级 | 名称 | 职能 | 覆盖范围 |
|------|------|------|----------|
| 第一级 | 基层医疗站 | 常见病诊治、预防保健、基础体检、急救转运 | 社区/村落/小型位面 |
| 第二级 | 区域医疗中心 | 专科诊疗、手术治疗、修炼损伤初步处理、康复 | 城市/区域/中型位面 |
| 第三级 | 高阶医疗总院 | 疑难重症、高阶修炼损伤、意识域疾病、跨种族疑难病 | 文明核心/大型位面 |

此外，设立"修炼损伤专科"：专门处理修炼过程中的各类损伤，包括能量过载、经脉断裂、心魔入侵、灵魂创伤等，配备精通修炼法则的医疗人员。

## 四、医疗保障基金

医疗保障基金是共生医疗体系运行的经济基础，其来源包括：

- 公共积累拨款（主要来源）
- 联产承包机制中的医疗保障提留
- 社会捐赠
- 基金投资收益

基金支付范围包括：基本医疗服务费用、急救费用、修炼损伤救治费用、基本药物费用、康复费用等。患者个人仅需支付少量自付费用，对经济困难者实行减免。

## 五、医疗机构与医务人员

- **公立医疗机构**：由国家或文明共同体设立，承担基本医疗服务与公共卫生职能，经费由医疗保障基金保障。
- **私立医疗机构**：由社会力量依法设立，可提供高端医疗服务，但必须接受医疗主管部门监管，不得拒绝急救患者。
- **异族医疗机构**：针对特殊种族生理需求设立的专科医疗机构，配备异族医疗人员。
- **医务人员权利与义务**：医务人员享有执业保护、合理报酬、职业培训等权利，同时负有救死扶伤、尊重患者、保守医密等义务。

## 六、公共卫生与预防

国家建立公共卫生体系，履行以下职能：

1. 传染病监测与防控，建立跨位面疫情预警机制。
2. 全民健康体检与健康档案管理。
3. 修炼安全宣传与修炼损伤预防指导。
4. 环境卫生与食品药品安全监管。
5. 突发公共卫生事件应急响应。

## 七、法律责任

违反本法规定的行为，视情节轻重承担以下责任：

- 医疗机构拒绝急救患者的，责令改正并处罚款，造成严重后果的吊销执业许可。
- 医务人员严重不负责任造成患者损害的，承担赔偿责任，情节严重的吊销执业资格。
- 医疗机构违规收费、过度医疗的，责令退还费用并处罚款。
- 泄露患者医疗隐私的，承担精神损害赔偿，情节严重的追究刑事责任。
- 生产销售假药、劣药的，没收违法所得并处罚款，构成犯罪的追究刑事责任。

## 结语

《医疗保障法》是锚点共生文明"人人有路"理念在健康领域的体现。它通过建立普遍覆盖的医疗保障体系、设立修炼损伤专科、保障急救救治权，确保每个生命在伤病时都能获得及时救治，为万族共进筑牢健康根基。
