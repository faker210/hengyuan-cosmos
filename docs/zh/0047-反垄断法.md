# 反垄断法

## 一、立法目的与基本原则

《反垄断法》是锚点共生文明五部配套法之一，旨在预防和制止垄断行为，保护市场公平竞争，提高经济运行效率，维护消费者利益与社会公共利益，促进共生经济的健康发展。在锚点共生文明中，反垄断不仅针对传统经济领域的垄断，更针对修炼资源垄断、知识垄断与位面垄断等特殊形态。

本法确立以下基本原则：

| 原则 | 内涵 |
|------|------|
| 公平竞争原则 | 维护公平竞争的市场秩序，禁止排除、限制竞争的垄断行为 |
| 反掠夺原则 | 反垄断的核心是反掠夺，防止垄断者通过垄断地位掠夺众生利益 |
| 资源开放原则 | 公共修炼资源与基础知识必须向全社会开放，禁止私人垄断 |
| 效率与公平平衡原则 | 反垄断既要保护竞争效率，也要防止过度分散导致的资源浪费 |
| 跨位面适用原则 | 反垄断法适用于衡元宙内一切位面与市场，跨位面垄断同样受规制 |

## 二、垄断行为的类型

本法规制的垄断行为包括以下四类：

### （一）垄断协议

垄断协议是指排除、限制竞争的协议、决定或者其他协同行为，包括：

1. **横向垄断协议**：具有竞争关系的经营者之间达成的固定价格、限制产量、分割市场、联合抵制交易等协议。
2. **纵向垄断协议**：经营者与交易相对人之间达成的固定转售价格、限定最低转售价格等协议。
3. **修炼资源垄断协议**：修炼宗门之间达成的划分修炼资源区域、统一资源价格、限制资源供给等协议。
4. **知识垄断协议**：教育机构与修炼宗门之间达成的封锁修炼法门、限制知识传播、统一学费标准等协议。

### （二）滥用市场支配地位

市场支配地位是指经营者在相关市场内具有能够控制商品价格、数量或者其他交易条件，或者能够阻碍、影响其他经营者进入相关市场能力的市场地位。滥用市场支配地位的行为包括：

| 行为类型 | 具体表现 |
|----------|---------|
| 不公平定价 | 以不公平的高价销售商品或以不公平的低价购买商品 |
| 掠夺性定价 | 没有正当理由，以低于成本的价格销售商品，排挤竞争对手 |
| 拒绝交易 | 没有正当理由，拒绝与交易相对人进行交易 |
| 限定交易 | 没有正当理由，限定交易相对人只能与其进行交易 |
| 搭售 | 没有正当理由搭售商品，或在交易时附加其他不合理条件 |
| 差别待遇 | 没有正当理由，对条件相同的交易相对人在交易价格等条件上实行差别待遇 |
| 修炼资源封锁 | 利用修炼资源垄断地位，拒绝向竞争者或消费者提供必要资源 |
| 知识封锁 | 利用知识垄断地位，封锁基础修炼法门，强迫学习者支付高额费用 |

### （三）经营者集中

经营者集中是指下列情形：经营者合并；经营者通过取得股权或者资产的方式取得对其他经营者的控制权；经营者通过合同等方式取得对其他经营者的控制权或者能够对其他经营者施加决定性影响。

达到申报标准的经营者集中，应当事先向反垄断执法机构申报，未申报的不得实施集中。反垄断执法机构审查经营者集中，应当考虑以下因素：

1. 参与集中的经营者在相关市场的市场份额及其对市场的控制力。
2. 相关市场的市场集中度。
3. 经营者集中对市场进入、技术进步的影响。
4. 经营者集中对消费者和其他有关经营者的影响。
5. 经营者集中对修炼资源开放与知识传播的影响。
6. 经营者集中对国民经济发展与万族共进的影响。

### （四）滥用行政权力排除、限制竞争

行政机关和法律、法规授权的具有管理公共事务职能的组织不得滥用行政权力，实施下列行为：

1. 限定或者变相限定单位或者个人经营、购买、使用其指定的经营者提供的商品。
2. 妨碍商品在地区之间、位面之间的自由流通。
3. 排斥或者限制外地经营者、外位面经营者参加本地招标投标活动。
4. 排斥或者限制外地经营者、外位面经营者在本地投资或者设立分支机构。
5. 强制经营者从事本法规定的垄断行为。
6. 制定含有排除、限制竞争内容的规定。

## 三、修炼领域的特殊反垄断规则

修炼领域是锚点共生文明反垄断的重点领域，本法设立特殊规则：

1. **基础法门开放义务**：三百套本源修炼体系的基础法门属于公共知识，任何组织和个人不得垄断、封锁或收费传授。
2. **修炼资源公平分配**：公共修炼资源通过联产承包机制公平分配，禁止宗门或个人垄断优质修炼资源。
3. **禁止修炼歧视**：修炼宗门在招生与传授中不得基于种族、出身、修为等设置歧视性条件。
4. **高阶知识共享义务**：达到位面至高强者标准的修炼者，有义务在保护合理知识产权的前提下，向社会分享其修炼心得与研究成果。
5. **位面开发反垄断**：新位面的开发权通过公开竞争方式分配，禁止少数势力垄断位面开发权。

## 四、反垄断执法机构

国家设立反垄断执法机构，负责反垄断执法工作，履行以下职责：

1. 研究拟订有关竞争政策。
2. 组织调查、评估市场总体竞争状况，发布评估报告。
3. 制定、发布反垄断指南。
4. 协调反垄断行政执法工作。
5. 查处垄断协议、滥用市场支配地位、违法实施经营者集中等案件。
6. 查处滥用行政权力排除、限制竞争行为。

反垄断执法机构依法独立行使职权，不受行政机关、社会团体和个人的干涉。

## 五、法律责任

违反本法规定的行为，视情节轻重承担以下责任：

- 达成并实施垄断协议的，责令停止违法行为，没收违法所得，并处上一年度销售额百分之一以上百分之十以下的罚款。
- 滥用市场支配地位的，责令停止违法行为，没收违法所得，并处上一年度销售额百分之一以上百分之十以下的罚款。
- 违法实施经营者集中的，责令停止实施集中、限期处分股份或者资产、限期转让营业，处五十万元以下的罚款。
- 滥用行政权力排除、限制竞争的，由上级机关责令改正，对直接负责的主管人员和其他直接责任人员依法给予处分。
- 垄断行为给他人造成损失的，依法承担民事赔偿责任。
- 情节严重构成犯罪的，依法追究刑事责任。

## 结语

《反垄断法》是锚点共生文明反掠夺主义在经济与修炼领域的法律武器。它通过规制垄断协议、滥用市场支配地位、经营者集中与行政垄断，特别是针对修炼资源垄断与知识垄断设立特殊规则，确保市场竞争与修炼资源的公平开放，防止垄断成为掠夺众生的新形式，为万族共进维护公平竞争的制度环境。
