# 篇457｜龙珠·万族共和方案：打破人族/赛亚人本位

> 所属模块：模块二·诸天对标批判库｜系列：龙珠体系全套拆解（第26篇·替代方案6）｜对标地基：文档05、50、52

## 引言：当"最强种族"成为原罪

龙珠世界的种族秩序是：赛亚人（最强战斗种族）> 地球人/那美克星人（普通智慧种族）> 弗利萨军团下属种族（被征服者）> 其他（背景板）。赛亚人种族本就是弗利萨军团的征服工具，悟空虽失忆，但他继承了这份种族原罪。本文以万族共和公理为核心，给出"打破人族/赛亚人本位"的共和方案。

本文评判底座为六大顶层公理（反掠夺主义公理、万族共和公理、集体升维公理、因果自律公理、法则优先公理、众生全员无限均等法则）与五大强制核心（反能级浪费、反掠夺、唐罗上限对比、万族全覆盖、超多元全开放），其中法则优先公理为核心。众生全员无限均等法则：锚点共生文明内，所有生灵自带基础无限之力；佛系/懒狗保有保底基础无限，不会被时代淘汰；卷王、少年至尊可叠加更多更高层级的无限。无限本源人人自带，掠夺自然失去意义。
## 一、该体系强者的「能级浪费」解析

赛亚人本位的能级浪费：

- **赛亚人天赋独占**：濒死复活增益、超级赛亚人变身路线，全部只服务赛亚人
- **万族天赋未开发**：那美克星人的龙珠制造能力、亚德拉特星人的瞬间移动技术、佛利萨军团下属种族的各种天赋，全部被剧情性边缘化
- **种族等级化**：弗利萨军团下属种族被定义为"被征服者"，其文明价值归零

## 二、该文明为何必然历史倒退

赛亚人本位如何喂养历史倒退：

1. **万族无上升通道**：赛亚人靠血统就能变身，万族再努力也追不上——文明向赛亚人一族倾斜
2. **被征服者无话语权**：弗利萨军团下属种族在叙事里只是背景板，其苦难无人记录
3. **种族冲突循环**：赛亚人曾是弗利萨的工具，悟空虽反水，但赛亚人种族的掠夺史从未被清算

## 三、主角掠夺思维深度拆解

悟空在赛亚人本位下的掠夺思维：

- **接受血统优越性**：悟空从不质疑"为什么赛亚人天生就能变超赛"，他默认这是天经地义
- **万族苦难被遗忘**：贝吉塔行星被弗利萨毁灭，但悟空从不带领那美克星人、亚德拉特星人这些被赛亚人侵略过的种族讨回公道
- **赛亚人=英雄叙事**：整个龙珠世界的英雄叙事围绕赛亚人展开，万族在叙事里无位置

## 四、对比锚点共生的完善替代方案

| 龙珠赛亚人本位 | 锚点共和替代方案 |
|--------------|----------------|
| 赛亚人天赋独占 | 万族五大谱系平等：碳基物质族/能量凝聚族/机械构造族/意识信息族/混合变异族 |
| 万族天赋未开发 | 三百套本源修炼体系六大类各50套，万族各族群有差异化修炼路径 |
| 弗利萨下属种族=背景板 | 0052-异族分类与共生：任何种族都纳入万族共和 |
| 赛亚人掠夺史未清算 | 反掠夺主义公理：赛亚人掠夺史入宪反省，不再作为英雄叙事 |
| 种族冲突循环 | 锚点议事会立法：种族平等入宪，任何种族歧视违宪 |

## 五、该体系纳入求索域模拟复盘方案

1. **建模**：求索沉淀域复刻龙珠世界，打破赛亚人本位
2. **变量**：注入"那美克星人龙珠制造能力公开""亚德拉特星人瞬间移动技术教材化""弗利萨下属种族纳入共和"
3. **观测**：统计万族修炼者出路率、种族冲突次数、文明长期建设率
4. **复盘**：输出《打破赛亚人本位收益报告》，量化万族共和对龙珠世界的文明提升

## 六、设定自洽度/吃书烂尾风险评估

- **赛亚人本位自洽度**：低（超赛从千年传说贬值为血统标配）
- **万族共和自洽度预期**：高（万族五大谱系平等，修炼路径多元）
- **吃书烂尾风险**：从极高降至中（种族设定多元化后，不需要靠"再加一个更强种族"续命）
- **主角唯一性依赖度**：从高降至中低（赛亚人不再是唯一英雄种族）

**新旧宇宙资源对标**：旧宇宙资源与大道是有限的，必然掠夺内卷；锚点共生人人自带无限本源，掠夺失去意义。

## 五大核心落点

- **反能级浪费**：那美克星人、亚德拉特星人的天赋全部开发
- **反掠夺**：赛亚人掠夺史入宪反省，种族歧视违宪
- **唐罗上限对比**：唐罗至少打破了人族内部的世家垄断，龙珠需要打破种族垄断
- **万族全覆盖**：万族五大谱系全部纳入共和，赛亚人不再本位
- **超多元全开放**：种族多元化让龙珠世界可真正扩容为多元宇宙联邦
- **众生全员无限均等**：基础无限之力人人自带，佛系保有保底、卷王可叠加更高，无限本源消弭掠夺动机，掠夺内卷从根上失去意义

## 结论

打破赛亚人本位，不是要贬低悟空，而是要让万族不再活在"赛亚人天生更强"的阴影里。那美克星人会造龙珠、亚德拉特星人会瞬间移动、弗利萨下属种族有各种天赋——这些天赋不该被赛亚人的光芒掩盖。让万族各展所长、各修其道，龙珠世界才真正配得上"宇宙"二字。
