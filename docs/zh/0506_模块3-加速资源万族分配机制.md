# 篇506｜本源加速域·万族共享加速资源的分配机制

> 所属模块：模块三·双轨时间域｜对标地基：文档22、06、94

## 引言：快的资源，凭什么归谁

本源加速域最稀缺的不是装置，而是**加速时间**。法则共振带宽、隔离空间算力、意识域能量供给，每一项都是硬约束。如果分配不公，加速域就会退化成强者的私人俱乐部，双轨时间域的全部设计就此作废。六大顶层公理是分配机制的宪法：反掠夺主义公理要求加速资源只奖励增量贡献，不奖励掠夺成果；万族共和公理要求五大谱系、男女老少、少年至尊与普通生灵一视同仁；集体升维公理要求加速资源向"抬万族一起升"的方向倾斜；因果自律公理要求分配过程公开可审计；法则优先公理要求分配算法稳定可复算，不临时偏袒。众生全员无限均等法则：锚点共生文明内，所有生灵自带基础无限之力；佛系/懒狗保有保底基础无限，不会被时代淘汰；卷王、少年至尊可叠加更多更高层级的无限。无限本源人人自带，掠夺自然失去意义。

本文拆解本源加速域的分配机制。

## 一、分配的三把尺子

加速资源的分配不看出身、不看修为高低，只看三把尺子：

1. **文明贡献度**：由联产承包机制（文档22）核算，记录个体对共生网络的增量贡献——研发了什么、救了多少生命、修了多少法则锚点；
2. **任务公共性**：任务越公共，优先级越高。救一个位面的灾难，优先于个人闭关突破；
3. **种族覆盖度**：为了确保99%全覆盖，每个加速域配额里必须保留一定比例给历史上被边缘化的种族与个体。

三把尺子合在一起，构成"贡献—公共—覆盖"三维评分。这个评分决定谁能开哪个档位、能开多久。

## 二、五大谱系的差异化折算

不同种族的"加速时间"价值不同，分配时必须折算：

| 谱系 | 时间折算系数 | 说明 |
|------|------------|------|
| 碳基物质族 | 1.0 | 基准 |
| 能量凝聚族 | 0.7 | 意识天然活跃，同等算力下效率更高 |
| 机械构造族 | 1.3 | 需额外能量供芯片计算，折算略高 |
| 意识信息族 | 0.5 | 几乎纯意识存在，加速效率极高 |
| 混合变异族 | 1.0–1.5 | 按构成比例个案核算 |

折算系数确保"效率高的种族"不会因为便宜而霸占资源，"效率低的种族"也不会因为贵而被挤出加速域。这是万族共和公理在分配层面的精确落地。

## 三、配额、轮转与救济

- **基础配额**：每个达到准入门槛的生灵，每年获得一笔基础加速时间，保证人人有得用；
- **贡献兑换**：超出基础配额的部分，用文明贡献度兑换，多劳多得；
- **轮转制**：热门档位（百速以上）采用排队轮转，杜绝强者长时间霸占；
- **救济通道**：遭遇文明级危机的位面或种族，可申请紧急配额，由锚点监督委员会审批后优先调度。

## 四、与唐罗"资源师承制"的对比

唐罗体系里，修炼资源（包括闭关室、时间加速地脉）按师承、血统、贡献（对宗门的贡献）分配，外围势力几乎无缘。衡元宙的分配机制则把"宗门忠诚"换成了"文明贡献"，把"血统"换成了"覆盖度"，把"独占"换成了"轮转"。一个来自偏远位面的碳基少年，只要做出足够的文明贡献，就能和道元境强者排在同一条队伍里。

## 四、分配机制的申诉与动态调整

分配不是一锤定音。每个季度，锚点监督委员会都会复核一次分配结果：如果某个种族的实际使用率长期低于配额，说明配额偏高；如果某个任务类型长期排不上队，说明配额偏低。复核结果公开，万族代表可在锚点议事会上提出调整动议。这种动态调整确保分配机制不会在运行几年后僵化，也不会被既得利益者固化成新的阶层。任何生灵如果认为自己被不公平地排除在某条路径之外，都可以向共生法院提起申诉，法院有权要求重新核算其贡献度与配额。

### 分配中的常见误解澄清

在执行过程中，有三种误解需要反复澄清：其一，"基础配额是否等于平均主义"——不是，基础配额只保障入场权，超额部分仍按贡献兑换；其二，"弱势种族是否会被特殊照顾"——不是特殊照顾，而是覆盖度修正，目的是把历史欠账补平，而不是无差别让利；其三，"配额能否转让"——不能，加速时间与实名身份绑定，转让视为变相交易，会被阿赖耶网络自动识别。澄清这三条，是分配机制长期不被腐蚀的前提。

## 五大核心落点

- **反能级浪费**：三维评分让加速时间流向公共性最高、贡献最大的任务，杜绝强者囤积
- **反掠夺**：掠夺所得不计入贡献度，靠吞噬积累的资源兑换不了加速时间
- **唐罗上限对比**：唐罗资源按师承分发，外围几代人追不上；衡元宙资源按贡献与覆盖分发，新人与旧族同场竞争
- **万族全覆盖**：差异化折算+基础配额+救济通道，确保99%种族与个体都能实际进入加速域
- **超多元全开放**：分配算法、折算系数、排队规则全部公开，新并入位面按同一套规则接入
- **公理六·众生全员无限均等**：所有生灵自带基础无限之力，佛系/懒狗保有保底基础无限不被时代淘汰，卷王与少年至尊可叠加更多更高层级的无限——无限本源人人自带，掠夺自然失去意义

## 结论

加速资源的分配，是双轨时间域是否真属于万族的试金石。贡献、公共、覆盖三把尺子，加上五大谱系的差异化折算，让"快"这件事第一次成了万族的公共品，而不是强者的私产。
