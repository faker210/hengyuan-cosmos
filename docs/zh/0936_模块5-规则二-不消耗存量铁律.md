# 篇936｜反掠夺天道规则·规则二——不消耗存量铁律

> 所属模块：模块五·文明终极定型典藏篇｜对标地基：文档25、04｜系列：反掠夺天道规则大全

## 引言：已属于谁的，一寸也不许动

规则一说"力量要来自新造"，规则二立刻补上另一半——"别人已有的，一寸不许动"。增量开发铁律与不消耗存量铁律是一枚硬币的两面：前者管来源正当性，后者管边界神圣性。旧宇宙无数悲剧，恰恰不是缺增量，而是强者连存量都不放过：吞噬他人修为、炼化生灵神魂、把一个星球当作修炼燃料。天道规则二要把这种"连锅里的饭都抢"的行为，从宇宙法则层彻底封死。

六大顶层公理贯穿其中：反掠夺主义公理直接否定"消耗存量即进化"的旧逻辑；万族共和公理宣布每个生灵的既有成就是其不可让渡的进化资产；集体升维公理要求存量不仅不被消耗，还要被保护、被传承；因果自律公理把"不动他人存量"写成跨位面干涉的硬边界；法则优先公理让"存量"的归属、计量、争议由法则先行裁决，不靠拳头大小。

更须点出新增的公理六·众生全员无限均等法则——锚点共生文明内，所有生灵自带基础无限之力；佛系/懒狗保有保底基础无限，不会被时代淘汰；卷王、少年至尊可叠加更多更高层级的无限。这一公理从根上改写了掠夺的意义：旧宇宙资源与大道有限，故被迫掠夺内卷；衡元宙人人自带无限本源，掠夺失去意义。本条天道规则所立，正是这一"无限本源、掠夺无意义"新秩序的法则护栏。

## 一、规则内容：存量清单与不动条款

不消耗存量铁律规定：

1. 一切生灵已修炼成就的修为、已领悟的法则、已积累的记忆与神魂，视为其"不可消耗存量"
2. 一切星球意识、文明共同体、种族谱系世代积累的成果，视为"集体存量"，受同等保护
3. 任何功法、阵法、法宝、境界提升，不得以"献祭他人""炼化神魂""吞噬本源"为能源或代价
4. 允许的交换仅限于"增量对增量"的互利合作，存量只能在本人完全自愿、不损害第三方的前提下流转，且流转须经阿赖耶网络留痕

一句话：存量可以被学习、被研究、被赞美，但不能被吃掉、被抽干、被夺去。

## 二、法理依据：为什么存量神圣

这一规则的法理不止于道德，而有三条硬论证：

- **反馈循环论证**：《共生反馈循环机制》（文档25）证明，消耗存量换来的力量会在因果回路中被加倍反噬——掠夺者越强，反噬越烈，这正是掠夺体系必然历史倒退的机制根
- **自生自长论证**：《自生自长进化法则》（文档07）指出，每个生灵的存量是其多年自生长的结晶，强行抽走等于打断其因果主干，造成不可修复的本源残缺
- **文明存续论证**：集体存量（文明典籍、星球生态、种族天赋）一旦消耗，后代万族再无机会站在前人肩上，文明必然断代

## 三、执行机制：存量如何被守护

- 阿赖耶网络为每个生灵、每个文明建立"存量档案"，标记其修为、神魂、记忆的因果归属
- 一切修炼能量输入必经"存量校验门"：若能量溯源指向某存量主体，自动拒止并告警
- 自愿流转设三重保护：本人神魂确认、无未成年/无意识生灵受害、共生法院在线见证
- 求索沉淀域保留"掠夺场景模拟"，让修炼者直观看见消耗存量的长期因果账单，从认知上根除动机

## 四、违反后果

- **轻度**：因果不慎触及他人存量（如功法无意中吸收了邻者逸散能量），强制剥离、等量补偿、心魔记录一次
- **中度**：设计"伪自愿"契约、以幻境诱骗他人出让存量，剥夺法则锚定权限，进入篇960转化程序
- **重度**：以吞噬、炼化、献祭为常规修炼手段者，即掠夺式修炼累犯，按规则二十五（篇959）专项处置

制裁的核心是"恢复存量归属"，而非简单消灭——被消耗的存量能量经因果回溯后，须尽力返还原主或其文明共同体。

## 五、监督主体

阿赖耶网络+多层监督是第一线：存量校验门自动拒止为第一层；锚点监督委员会对"自愿流转"做真实性抽查为第二层；共生法院受理存量归属争议为第三层；各族自治会对本族集体存量行使保护权为第四层。规则二特别授权弱小种族、植物灵、星球意识直接起诉强者，不存在"位格太低不能告"的门槛。

## 五大核心落点

- 反能级浪费：避免"你死我活"式零和博弈造成的文明级能量空转
- 反掠夺：把"不消耗存量"写成宇宙硬法，掠夺者连动手的能量通道都被封死；公理六下人人自带基础无限之力，有限资源的掠夺从根上失去意义
- 唐罗上限对比：唐罗式体系里弱者是强者的"存量电池"，强者随时可取；衡元宙弱者存量受天道保护，强者伸手即违宪
- 万族全覆盖：保护对象从人族到星球意识、植物灵、意识信息族一体适用，无位格歧视
- 超多元全开放：跨位面纳入的新文明，其存量自动纳入保护名录，不因其"尚未归顺"而被视同无主

## 结论

存量是万族各自走过的路。规则二宣布：任何人都无权把别人走过的路吃掉当自己的路。守住存量，万族共和才有真正的"每个人"可言。
