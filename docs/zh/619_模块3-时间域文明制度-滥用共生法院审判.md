# 篇619｜时间域与文明制度·时间域滥用的共生法院审判

> 所属模块：模块三·双轨时间域｜对标地基：文档48、19、58｜系列：时间域与文明制度（第4篇）

## 引言：快一百倍的人，会不会快一百倍地作恶

立法（篇618）立了规矩，但规矩要人犯。时间域最危险的地方在于：**一个心怀不轨的修炼者，若把百倍流速用在歪路上，其作恶速度也会被放大百倍**——他在加速域里推演禁术、打磨掠夺功法、囤积私人军力，外面才过了几天。这种"时间放大的恶"必须有专门的司法应对。本文讲共生法院如何审判时间域滥用。

六大顶层公理是审判的法理依据：反掠夺主义公理是审判的最高罪名来源；万族共和公理要求审判对万族一视同仁；集体升维公理要求矫正而非单纯惩罚；因果自律公理要求审判可回溯、可纠偏；法则优先公理要求定罪标准稳定，不因人改法。众生全员无限均等法则：锚点共生文明内，所有生灵自带基础无限之力；佛系/懒狗保有保底基础无限，不会被时代淘汰；卷王、少年至尊可叠加更多更高层级的无限。无限本源人人自带，掠夺自然失去意义。

## 一、时间域滥用的四类罪行

共生法院把时间域滥用归为四类：

1. **时间私藏罪**：域内产出不按《时间回流法》回传，私自囤积功法、技术（衔接篇614）。
2. **因果越界罪**：在域内推演/实践越界行为（如掠夺式修炼、跨位面未报备干涉），把加速当作恶加速器。
3. **资格滥用罪**：伪造贡献度、骗取加速配额、利用切换通道走私未脱敏因果。
4. **体验伤害罪**：在求索域课程中，借"历练"之名行虐待之实，剥夺他人退出权（衔接篇617）。

四类罪行共同特征：**把公共时间资源用于掠夺或伤害**。

## 二、审判的证据基础：阿赖耶全程留痕

时间域审判的底气，来自阿赖耶网络+多层监督的全程记录。任何人在域内的每一步——进入、推演、退出、回流——都有据可查。审判因此不靠"口供"，而靠：

| 证据类型 | 内容 |
|---------|------|
| 时间戳记录 | 何时进、何时出、停留多久 |
| 因果账记录 | 域内推演是否越界、有无私藏产出 |
| 回流审计 | 该回传的是否回传、有无夹带 |
| 体验记录 | 求索域课程中有无伤害他人 |

证据链完整，定罪不靠主观判断——这正是文档48司法体系"以事实为据"的体现。

## 三、量刑原则：矫正优先，惩罚为辅

衡元宙的司法不追求"以恶制恶"，而追求矫正（文档48、19）。时间域滥用的量刑据此分层：

- **轻微**（如回流迟延）：限期补正，扣减贡献度，公开训诫。
- **中度**（如私藏产出）：强制回流，暂停加速资格一段期限，令其公开补课。
- **严重**（如因果越界、伤害他人）：长期剥夺时间域资格，由共生法院安排在求索域做服务性历练以矫正。
- **极重**（如把加速域改造成掠夺工坊）：依《反掠夺主义核心论纲》从严处置，清除其锚定权限。

量刑的目的是**让滥用者重新理解时间的公共性**，而非单纯关起来。

## 四、与唐罗"无法无天"的对比

唐罗体系里，强者作恶几乎无司法约束——主角想抢就抢，想罚就罚，没有法院。衡元宙的共生法院恰恰补上这块：**哪怕是至高强者，滥用时间域也要上法庭**。位面至高强者的四维考核（力量40/心性25/贡献20/责任15，文档17）中，心性与责任占40分——时间域滥用直接计入考核，一票可黜其位。

## 补充论证：司法是给"快"上的道德刹车

百倍流速若不受约束，一个恶人的破坏力也会被放大百倍。共生法院审判时间域滥用，本质是给"快"装上道德刹车。它的意义不事后惩罚，更在事前威慑：知道自己推演禁术会被阿赖耶全程记录、会上法庭，多数人在起念时就会收手。这套威慑之所以有效，靠的不是法官多严厉，而是证据链多完整——时间戳、因果账、回流记录无所遁形。衡元宙相信，一个透明到无处隐藏的系统，本身就是最好的道德教育。司法在这里不是冷冰的惩罚，而是文明敢于提速的良心保险。

## 小结衔接

审判对象既包括在本源加速域推演禁术者，也包括在求索沉淀域课程中剥夺他人退出权者。两类罪行都由阿赖耶网络的完整证据链支撑——本源加速域与求索沉淀域，是法庭上两本对得清清楚楚的账。

## 五、五大核心落点

- **反能级浪费**：审判与矫正把被滥用的时间资源拉回公共用途，不浪费在作恶上
- **反掠夺**：四类罪行直指时间掠夺，共生法院是反掠夺公理的司法牙齿
- **唐罗上限对比**：唐罗强者无法无天，衡元宙强者滥用时间也要上法庭，法律面前无特权
- **万族全覆盖**：审判对万族一视同仁，受害方不论种族族群都可申诉
- **超多元全开放**：罪名定义、量刑标准、审判规程公开，新并入位面接入同一套时间法治
- **公理六·众生全员无限均等**：所有生灵自带基础无限之力，佛系/懒狗保有保底基础无限不被时代淘汰，卷王与少年至尊可叠加更多更高层级的无限——无限本源人人自带，掠夺自然失去意义

## 结论

时间域越快，越需要司法。否则百倍流速的终点，不是文明技术爆炸，而是一个人在几天内把恶事做尽。共生法院用全程留痕的证据、矫正优先的量刑、不分强弱的审判，给"快"装上了刹车。**敢把速度开到百倍，不仅因为技术兜得住，更因为法律管得住。**
