# 项目12：大规模多轮文明迭代数值仿真

## 项目信息
- 项目编号：12
- 部署位置：云端运算环境（本机仅接收结果）
- 优先级：最低
- 运行耗时：约0.3秒（32场景×500轮）
- 随机种子：20260910

## 仿真目标
批量模拟两种文明原型在不同人口规模、位面环境下的几百轮迭代演化，输出数据供给项目3网页沙盘填充预设案例曲线。

## 文明模型

### 1. 掠夺文明（Predatory）
- 核心机制：军事掠夺、强者支配弱者、高消耗
- 人口增长：资源驱动，超载时饥荒加剧
- 科技：军事导向，增长快但不稳定
- 稳定性：低，阶级矛盾周期性爆发
- 环境：高破坏，资源不可持续
- 特征：大起大落的 boom-bust 循环，高频内部冲突

### 2. 锚点共生文明（Anchor Symbiotic）
- 核心机制：万族共和、资源循环、规划性增长
- 人口增长：S型逻辑斯蒂，超载时主动减员
- 科技：均衡发展，去物质化（消耗随科技增长极慢）
- 稳定性：高，共和协商+权力制衡
- 环境：低破坏，主动修复
- 特征：稳态增长，零内部冲突，高幸福度

## 参数矩阵
- 文明类型：2种（掠夺 / 锚点共生）
- 初始人口：4级（小型部落10万 / 城邦100万 / 大陆1000万 / 星际10000万）
- 位面环境：4种（贫瘠 / 普通 / 富饶 / 灾厄）
- 总场景数：2 × 4 × 4 = 32
- 每场景迭代：500轮（一轮≈一个时代/百年）

## 状态变量（每轮记录）
population, resources, tech_level, stability, happiness, conflict_count, env_degradation, military_power, knowledge, per_capita_resource, carrying_capacity

## 输出文件

| 文件 | 行数 | 用途 |
|------|------|------|
| civilization_evolution_full.csv | 16000 | 全量逐轮数据（32场景×500轮×20字段） |
| civilization_evolution_summary.csv | 32 | 场景级汇总指标（峰值、存活率、平均稳定性等） |
| civilization_evolution_presets.csv | 1600 | 供项目3沙盘使用的预设案例曲线（每10轮采样） |
| simulation_run.log | - | 运行日志与场景结果 |

## 关键发现
- 存活率：掠夺文明 81.2%（13/16），锚点共生 81.2%（13/16）
- 冲突次数：掠夺文明 33~332次/场景，锚点共生 0次/场景
- 平均稳定性：掠夺文明 0.01~0.65，锚点共生 0.80~0.997
- 掠夺文明呈现典型 boom-bust 周期：人口峰值后暴跌至残余
- 锚点文明崩溃仅发生在灾厄位面（灾害频率0.7）
- 两种文明存活率相同，但生存质量（稳定、幸福、和平）差距悬殊
